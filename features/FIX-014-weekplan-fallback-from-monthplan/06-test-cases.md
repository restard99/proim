# FIX-014 테스트 케이스

## 테스트 전 준비사항
- `/executive/report` 접근 권한(임원실 또는 관리자)
- 태평염전 월간계획을 화면에서 확인하려면, 관리자가 "매출목표관리 > 매출/생산"에서 워크북을 다시 한번 업로드해야 함(코드 수정만으로는 기존 저장 데이터가 채워지지 않음)

## 정상 케이스

### TC-001: 태평소금 주간계획 대체값 표시
**조건:** 태평소금(0460)의 이번 주에 명시적 주간계획이 없고, 이번 달 월간계획은 있음
**단계:**
1. `/executive/report`에서 "1. 전 사업장 매출실적" 탭을 연다
2. 태평소금 행의 "주간 계획" 열을 확인한다
**기대 결과:** "미입력"이 아니라 "월간계획 ÷ 그 달 일수 × 7"로 계산된 숫자가 표시된다
**결과:** [ ] 통과 / [ ] 실패

### TC-001b: 달을 걸치는 주 주간계획 합산 (워크북 재업로드 후)
**조건:** 관리자가 수정된 파서로 워크북을 다시 업로드한 상태
**단계:**
1. 📅 기간 조회 또는 날짜 이동으로 8/31~9/6 주(또는 그 이후 달을 걸치는 아무 주)로 이동한다
2. 태평소금 행의 "주간 계획" 열을 확인한다
**기대 결과:** 월말 날짜 몫 + 그 주 나머지 몫이 합산된 값(예: 149,315,000)이 표시된다(9월 몫만 반영된 더 작은 값이 아님)
**결과:** [ ] 통과 / [ ] 실패

### TC-002: 태평염전 월간계획 표시 (워크북 재업로드 후)
**조건:** 관리자가 수정된 파서로 워크북을 다시 업로드한 상태
**단계:**
1. "매출목표관리 > 매출/생산"에서 최신 "주간_월간_업무보고" 워크북을 다시 업로드한다
2. `/executive/report`의 "1. 전 사업장 매출실적"에서 태평염전 행을 확인한다
**기대 결과:** 월간계획이 "미입력"이 아니라 해당 월의 목표 금액으로 표시된다(주간계획도 월간계획 기반 대체값으로 함께 표시됨)
**결과:** [ ] 통과 / [ ] 실패
