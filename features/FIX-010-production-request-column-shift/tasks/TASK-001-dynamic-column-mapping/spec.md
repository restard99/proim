# TASK-001: 헤더 라벨 기반 동적 열 매핑

## 목적
`parseProductionRequestWorkbook`이 열 위치를 하드코딩하지 않고 헤더 행의 라벨 문구로 각 필드의 실제 열 번호를 찾도록 고친다. 매핑되지 않은 열(예: "구분")의 값은 버리지 않고 비고(remark)에 포함시킨다.

## 작업 범위
- 수정할 파일: `lib/production-requests/parse.ts`
  - 헤더 행 텍스트를 읽어 라벨→열번호 맵을 만드는 로직 추가
  - 항목 행 파싱 시 하드코딩된 `t[1]`, `t[2]`... 대신 위 맵으로 조회
  - "소계" 합계 행 파싱도 동일하게 동적 열번호 사용
  - remark = 매핑된 필드 열들을 제외한 나머지 열(구분 포함) 전체를 순서대로 합친 값
  - 기존 파일(구분 열 없음)도 동일 코드 경로로 정상 파싱되는지 확인

- [ ] "구분" 열의 값(예: "3공장")이 remark에 포함됨
- [ ] 예전 파일(`★생산의뢰서(0901).xlsx` 등, 구분 열 없음)도 기존과 동일하게 정상 파싱됨 (회귀 없음)
