# 관리자 계정으로 보기(View As) 테스트 케이스

## 테스트 전 준비사항
- 관리자(admin) 계정 1개
- 승인된(approved) 일반 계정이 최소 2개 부서에 걸쳐 존재해야 함 (예: 영업팀 1명, 생산팀 1명)
- 가능하면 업무일지 등 "작성자"가 남는 화면이 하나 있는 부서로 테스트하면 TC-005 확인이 쉬움

## 정상 케이스

### TC-001: 담당자 선택 화면 진입
**조건:** 관리자 계정으로 로그인
**단계:**
1. 왼쪽 사이드바 "관리자" 섹션에서 "시스템검토 게시판" 클릭
**기대 결과:** `/admin/view-as`로 이동, 부서 탭과 첫 번째 부서의 담당자 목록이 보인다
**결과:** [ ] 통과 / [ ] 실패

### TC-002: 부서 탭 전환
**조건:** TC-001 화면
**단계:**
1. 다른 부서 탭 클릭
**기대 결과:** 그 부서 소속 담당자 목록으로 바뀐다
**결과:** [ ] 통과 / [ ] 실패

### TC-003: 담당자 계정으로 전환
**조건:** TC-001 화면
**단계:**
1. 담당자 카드 클릭
**기대 결과:** "전환하는 중..." 표시 후 홈 화면으로 이동. 왼쪽 사이드바 메뉴가 그 담당자의 부서 메뉴로 바뀌고, 우측 상단 이름도 그 담당자 이름으로 바뀐다
**결과:** [ ] 통과 / [ ] 실패

### TC-004: 전환 중 복귀 배너 표시
**조건:** TC-003 완료 직후
**단계:**
1. 화면 최상단 확인
**기대 결과:** 크림슨색 배너에 "OO님(부서)으로 보는 중"과 "관리자로 복귀" 버튼이 보인다. 다른 페이지로 이동해도 배너가 계속 보인다
**결과:** [ ] 통과 / [ ] 실패

### TC-005: 전환된 계정으로 실제 데이터 입력
**조건:** TC-003 완료 상태
**단계:**
1. 그 담당자 권한으로 볼 수 있는 화면(예: 업무일지)에서 데이터를 하나 입력/저장
**기대 결과:** 저장이 정상적으로 되고, 작성자로 그 담당자 이름이 남는다 (관리자 이름이 아님)
**결과:** [ ] 통과 / [ ] 실패

### TC-006: 관리자로 복귀
**조건:** TC-004 화면
**단계:**
1. 배너의 "관리자로 복귀" 클릭
**기대 결과:** `/admin/view-as`로 이동하고, 사이드바/우측 상단이 다시 관리자 정보로 돌아온다. 배너가 사라진다
**결과:** [ ] 통과 / [ ] 실패

## 예외 케이스

### TC-007: 담당자가 없는 부서
**조건:** 계정이 하나도 없는 부서가 있는 경우
**단계:**
1. `/admin/view-as`에서 해당 부서 탭 클릭
**기대 결과:** "OO에 등록된 계정이 없습니다" 빈 상태 문구가 보인다
**결과:** [ ] 통과 / [ ] 실패

### TC-008: 일반 계정에는 메뉴/접근 모두 차단
**조건:** admin이 아닌 계정으로 로그인
**단계:**
1. 사이드바에 "관리자" 섹션이 있는지 확인
2. 주소창에 직접 `/admin/view-as` 입력해서 접속 시도
**기대 결과:** 사이드바에 "관리자" 섹션이 없다. 직접 접속 시도는 홈(`/`)으로 리다이렉트된다
**결과:** [ ] 통과 / [ ] 실패

### TC-009: 전환 상태에서 관리자 전용 메뉴 재접근 차단
**조건:** TC-003 완료 상태 (담당자 계정으로 보는 중)
**단계:**
1. 사이드바에 "관리자" 섹션이 있는지 확인
2. 주소창에 직접 `/admin/view-as` 입력해서 접속 시도
**기대 결과:** 사이드바에 "관리자" 섹션이 보이지 않는다. 직접 접속 시도는 홈(`/`)으로 리다이렉트된다 (지금 세션은 담당자 권한이라 관리자 화면에 들어갈 수 없음 — 먼저 배너로 복귀해야 함)
**결과:** [ ] 통과 / [ ] 실패

### TC-010: 새로고침 후에도 전환 상태 유지
**조건:** TC-003 완료 상태
**단계:**
1. 브라우저 새로고침(F5)
**기대 결과:** 로그아웃되지 않고 그대로 담당자 계정으로 보는 중 상태와 배너가 유지된다
**결과:** [ ] 통과 / [ ] 실패

### TC-011: 전환 중 로그아웃
**조건:** TC-003 완료 상태
**단계:**
1. 배너로 복귀하지 않고 사이드바 프로필 영역에서 바로 "로그아웃" 클릭
2. 관리자 계정으로 다시 로그인
**기대 결과:** 정상적으로 로그아웃/재로그인되고, 관리자로 다시 로그인했을 때 예전 전환 상태가 남아있지 않다 (배너 없음, 정상 관리자 화면)
**결과:** [ ] 통과 / [ ] 실패
