# 관리자 계정으로 보기(View As) 기획서

## 개요
시스템 관리자가 부서/담당자를 선택하면, 그 담당자 계정으로 로그인한 것처럼 화면을 직접 확인·조작할 수 있는 기능.

## 사용자
시스템 관리자(admin)

## 해결하는 문제
각 부서 담당자 화면이 실제로 어떻게 보이고 동작하는지 확인하려면 매번 해당 계정으로 로그아웃/로그인을 반복해야 해서 테스트가 번거롭다.

## 기대 효과
관리자가 `/admin/view-as` 페이지에서 부서 탭을 선택하고 담당자를 클릭하면, 별도 로그인 없이 즉시 그 담당자 권한으로 전환되어 화면을 확인할 수 있다. 언제든 상단 배너의 버튼 한 번으로 관리자 계정으로 복귀한다.

## 범위

### 포함
- `/admin/view-as` 페이지: 상단 부서 탭(영업팀 / 영업채산팀 / 생산팀 등) + 선택한 부서의 담당자 리스트
- 담당자 클릭 시 해당 계정으로 전환 — 그 사람의 팀/권한 기준으로 사이드바 메뉴·데이터가 그대로 보임(로그인한 것과 동일하게 동작, 조회뿐 아니라 입력/수정도 가능)
- 전환 중에는 모든 화면 상단에 고정 배너 표시: "OO님(부서)으로 보는 중 · 관리자로 복귀" + 복귀 버튼
- 복귀 버튼 클릭 시 즉시 관리자 계정으로 돌아옴

### 제외
- 사용 기록(감사 로그) 남기지 않음
- 다른 관리자 계정으로의 전환은 대상에서 제외 (일반 담당자 계정만 대상)
- 담당자 화면으로 전환된 상태에서는 그 담당자 권한 그대로 동작 — 관리자 전용 메뉴(가입 승인 등)는 노출하지 않음
