# FIX-012 테스트 케이스

## 테스트 전 준비사항
- 브라우저의 "종료 시 이전 세션 계속 열기"(예: Chrome의 "시작 그룹" 설정, 창을 닫아도 탭 복원) 옵션이 꺼져 있어야 정확히 테스트된다. 켜져 있으면 브라우저 자체가 세션 쿠키까지 보존해 결과가 다르게 나올 수 있다.

## TC-001: 쿠키가 세션 쿠키로 발급되는지 확인
**단계:**
1. 로그인한다
2. 개발자도구 → Application(Chrome) / 저장소(Firefox) → Cookies에서 `sb-*-auth-token` 계열 쿠키의 만료(Expires/Max-Age) 값을 확인한다
**기대 결과:** 만료 값이 "Session"으로 표시됨 (날짜가 찍혀있지 않음)
**결과:** [ ] 통과 / [ ] 실패

## TC-002: 브라우저 완전 종료 후 재접속
**단계:**
1. 로그인한다
2. 브라우저를 완전히 종료한다(모든 창 닫기, 백그라운드 프로세스까지 종료 — 작업관리자에서 확인 권장)
3. 브라우저를 다시 실행해 사이트에 접속한다
**기대 결과:** 로그인 화면이 뜬다 (자동으로 이전 계정에 접속되지 않음)
**결과:** [ ] 통과 / [ ] 실패

## TC-003: 탭/새로고침만으로는 로그인 유지
**단계:**
1. 로그인한다
2. 브라우저는 끄지 않고 탭만 닫았다가 새 탭으로 다시 접속, 또는 새로고침(F5)한다
**기대 결과:** 로그인 상태가 그대로 유지된다 (재로그인 필요 없음)
**결과:** [ ] 통과 / [ ] 실패

## TC-004: 기존 로그아웃 버튼 정상 동작
**단계:**
1. 로그인 상태에서 사이드바의 "로그아웃" 버튼 클릭
