# FIX-012: 브라우저를 완전히 닫으면 로그인 세션 종료

## 문제 상황
로그인한 채로 브라우저를 닫고 다음날 다시 열면, 로그아웃한 적이 없기 때문에 여전히 로그인된 상태로 접속된다. Supabase SSR 클라이언트가 인증 쿠키에 기본 400일짜리 유효기간을 부여해서, 브라우저를 닫아도 쿠키가 남아 있는 게 원인이다.

## 현재 동작
- `lib/supabase/client.ts`/`lib/supabase/server.ts`가 쿠키 옵션을 지정하지 않아 `@supabase/ssr`의 기본값(`maxAge: 400일`)이 적용됨
- 로그인 후 브라우저를 완전히 종료했다가 다시 열어도 로그인 상태가 유지됨

## 기대 동작
- 로그인 세션 쿠키를 "세션 쿠키"(만료 시간 미지정)로 발급해, 브라우저를 완전히 종료하면 쿠키가 삭제되고 다음 접속 시 로그인 화면이 뜨도록 한다
- 브라우저를 닫지 않고 계속 켜둔 채로 쓰는 동안(같은 근무일 안)에는 기존처럼 로그인 상태가 유지되어야 한다 (탭만 닫는 것은 영향 없음)
- 기존 "로그아웃" 버튼 동작은 그대로 유지

## 영향 범위
- `lib/supabase/client.ts`, `lib/supabase/server.ts`: 쿠키 옵션에 `maxAge`/`expires`를 지정하지 않도록(세션 쿠키로) 수정
- 로그인/회원가입/비밀번호 재설정 등 인증이 걸리는 모든 화면에 영향 (세션 유지 방식만 바뀌고 로직은 그대로)
