# TASK-001: 인증 쿠키를 세션 쿠키로 변경

## 목적
Supabase 인증 쿠키에 만료 시간을 주지 않아, 브라우저를 완전히 닫으면 쿠키가 삭제되고 다음 접속 시 재로그인이 필요하도록 만든다.

## 작업 범위
- 수정할 파일: `lib/supabase/client.ts`, `lib/supabase/server.ts`

## 완료 기준
- [ ] 두 클라이언트 모두 `cookieOptions`(또는 `cookies.setAll`에서 옵션 재정의)로 `maxAge`/`expires`를 제거해 세션 쿠키로 발급
- [ ] 로그인 → 브라우저 완전 종료 → 재실행 시 로그인 화면으로 이동 (개발자도구로 쿠키 만료값이 "Session"인지 확인)
- [ ] 로그인 상태에서 새로고침/새 탭만으로는 로그인 유지됨 (기존 동작 그대로)
- [ ] 기존 로그아웃 버튼 정상 동작
- [ ] `npx tsc --noEmit` 통과
