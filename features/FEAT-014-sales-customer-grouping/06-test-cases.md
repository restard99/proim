1. "거래처별 매출" 화면에서 이마트 지점이 여러 건 있는 기간을 조회한다
**기대 결과:** "이마트" 행 하나로 합산 금액이 표시되고, "(N개 지점)"이 붙는다
**결과:** [ ] 통과 / [ ] 실패

### TC-002: 클릭 시 지점별 세부내역 펼치기
**단계:**
1. "이마트" 행을 클릭한다
**기대 결과:** 지점별 개별 거래처명/금액이 들여쓰기된 행으로 펼쳐진다. 다시 클릭하면 접힌다
**결과:** [ ] 통과 / [ ] 실패

### TC-003: 롯데렌탈/이노베이트 제외 확인

**기대 결과:** 이 두 거래처는 "롯데" 그룹에 안 들어가고 개별 행으로 표시된다
**결과:** [ ] 통과 / [ ] 실패

**기대 결과:** "지에스" 그룹에 안 들어가고 개별 행으로 표시된다

**기대 결과:** 개별 행으로 그대로 표시되고 클릭해도 펼쳐지지 않는다
**결과:** [ ] 통과 / [ ] 실패

### TC-007b: 월간/월누적 — 업체별 제품 내역 펼치기
**단계:**
1. "월간" 또는 "월누적" 탭에서 그룹(예: 롯데) 또는 개별 거래처 행을 클릭한다
**기대 결과:** 업체별로 소제목이 뜨고, 그 아래 제품명/수량/금액 목록이 표시된다(제품 합계가 업체 매출액과 일치)
**결과:** [ ] 통과 / [ ] 실패

### TC-007c: 주간 탭은 기존 방식 유지
**단계:**

**기대 결과:** 업체별 제품 내역이 아니라 기존처럼 지점별 금액만 펼쳐진다. 그룹이 아닌 개별 거래처는 클릭해도 아무 반응이 없다
**결과:** [ ] 통과 / [ ] 실패
