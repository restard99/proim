# FEAT-014: 거래처별 매출 — 센터·지점별 합산 + 세부내역 펼쳐보기

## 개요
"거래처별 매출" 화면에서 이마트/롯데/지에스처럼 센터(지점)별로 흩어져 있는 거래처를 브랜드 단위로 합쳐서 하나의 행으로 보여준다. 행을 클릭하면 원래 지점별 세부내역을 펼쳐볼 수 있다.

## 사용자
영업부 — 거래처별 매출 조회 화면 사용자

## 해결하는 문제
Y-ERP에는 "이마트 안양점", "이마트 가양점"처럼 지점마다 별도 거래처 코드로 등록돼 있어, 브랜드 단위 총 매출을 보려면 화면에서 일일이 더해봐야 했다.

## 기대 효과
이마트/롯데/지에스/농협/신세계/샘표/해표/섬들채(기존 표시 우선순위 그룹과 동일)가 브랜드 하나로 합쳐져서 바로 총액을 확인할 수 있고, 필요하면 클릭해서 지점별 내역도 볼 수 있다.

## 범위
### 포함
- 위 8개 그룹의 합산 표시 + 클릭 시 지점별 세부내역 펼치기/접기
- 그룹에 속하지 않는 거래처는 기존처럼 개별 행으로 표시

### 제외
- 그룹 정의 자체를 화면에서 편집하는 기능(그룹/별칭은 코드에 고정)
- "거래처 수" 카드의 집계 기준 변경(여전히 Y-ERP 원본 거래처 코드 수 기준)

## 그룹 정의(사용자 확인, 실제 거래처명 전수 대조 후 확정)
- **롯데**: "롯데" 포함이면 다 합침(롯데마트/슈퍼/Market999/VIC마켓/프리미엄푸드마켓 등) — 단, **롯데렌탈·롯데이노베이트**(비유통 계열사)는 제외
- **지에스**: "지에스"가 아니라 **"지에스리테일"**로 매칭 — 한국에스지에스(SGS)·지에스넷비전 같은 우연한 오매칭 자동 배제
- **농협**: "농협" 포함이면 합치되, **은행/카드/우유**(농협은행, NH농협카드, 서울우유농협 — 매출 거래처가 아니라 자금 관련 계정/별개 조합) 제외
- **이마트**: "(주)부방유통 이마트 안양점"도 포함(사용자 확인 — 납품 대행업체로 보이지만 합쳐서 보기로 함)
- **샘표**: "샘표식품 주식회사 (X)"(비활성 중복 코드로 추정) 별도 처리 없이 그대로 그룹에 포함(사용자 확인 — 무시해도 된다고 함)
- 신세계/섬들채/해표(사조대림)는 기존 표시 우선순위 그룹 정의를 그대로 사용(별도 이견 없음)
