# 메인화면 뼈대 테스트 케이스

## 테스트 전 준비사항
- 승인 완료(`status = approved`) 상태의 테스트 계정 1개 이상 (이름, 소속팀, 비밀번호 확인)
- 가능하면 승인 대기(`status = pending`) 상태의 계정도 1개 (TC-007용, 없으면 생략 가능)
- 데스크톱 브라우저 창(가로 폭 충분히 넓게)과 모바일 폭(또는 브라우저 개발자도구 반응형 모드) 둘 다 테스트

## 정상 케이스

### TC-001: 로그인 후 홈 화면 진입
**조건:** 승인 완료된 계정 보유
**단계:**
1. 로그인 화면에서 이름/소속팀/비밀번호로 로그인
**기대 결과:** 로그인 후 좌측에 사이드바(로고, 홈/일정관리/업무일지 탭, 하단 내 이름·소속팀)가 보이는 홈 화면(`/`)으로 이동하고, "홈" 탭이 강조 표시됨
**결과:** [ ] 통과 / [ ] 실패

### TC-002: 일정관리 탭 이동
**조건:** TC-001 로그인 상태
**단계:**
1. 사이드바에서 "일정관리" 탭 클릭
**기대 결과:** 주소가 `/schedule`로 바뀌고, 상단 제목이 "일정관리"로 바뀌며, 사이드바에서 "일정관리" 탭이 강조 표시됨. 화면 중앙에 "일정관리 화면 준비 중입니다" 문구가 보임
**결과:** [ ] 통과 / [ ] 실패

### TC-003: 업무일지 탭 이동
**조건:** TC-001 로그인 상태
**단계:**
1. 사이드바에서 "업무일지" 탭 클릭
**기대 결과:** 주소가 `/worklog`로 바뀌고, 상단 제목이 "업무일지"로 바뀌며, "업무일지" 탭이 강조 표시됨. "업무일지 화면 준비 중입니다" 문구가 보임
**결과:** [ ] 통과 / [ ] 실패

### TC-004: 사이드바 하단 사용자 정보 표시
**조건:** TC-001 로그인 상태
**단계:**
1. 사이드바 하단 영역 확인
**기대 결과:** 로그인한 계정의 이름과 소속팀이 정확히 표시됨
**결과:** [ ] 통과 / [ ] 실패

### TC-005: 모바일 화면에서 메뉴 열기/닫기
**조건:** TC-001 로그인 상태, 브라우저 폭을 모바일 크기로 축소(또는 개발자도구 반응형 모드)
**단계:**
1. 좌측 사이드바가 사라지고 상단에 햄버거 버튼이 보이는지 확인
2. 햄버거 버튼 클릭
3. 슬라이드로 나타난 메뉴에서 "일정관리" 탭 클릭
4. 다시 햄버거 버튼으로 메뉴를 열고, 메뉴 바깥의 어두운 배경을 클릭
**기대 결과:** 2번에서 메뉴가 좌측에서 슬라이드로 나타남. 3번에서 `/schedule`로 이동하며 메뉴가 자동으로 닫힘. 4번에서 배경 클릭 시 메뉴가 닫힘
**결과:** [ ] 통과 / [ ] 실패

### TC-007: 승인 대기 중인 계정으로 접근
**조건:** 승인 대기(`pending`) 상태 계정 보유 시에만 진행
