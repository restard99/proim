# 메인화면 뼈대 기획서

## 개요
로그인 후 진입하는 메인화면에 탭 방식 네비게이션(홈 / 일정관리 / 업무일지)을 구축하여, 각 화면으로 이동할 수 있는 뼈대를 만든다. 각 화면의 실제 기능은 이후 별도 기능으로 개발한다.

## 사용자
전 직원 공통 (역할 구분 없음)

## 해결하는 문제
로그인 후 각 부서/기능 화면으로 이동할 방법이 없다.

## 기대 효과
로그인하면 탭(홈 / 일정관리 / 업무일지)이 보이고, 탭을 클릭하면 해당 화면(뼈대)으로 이동한다. 이후 각 화면의 세부 기능을 이 뼈대 위에 이어서 개발할 수 있다.

## 범위
### 포함
- 로그인 후 진입하는 메인 레이아웃 (탭/네비게이션 UI)
- 홈, 일정관리, 업무일지 3개 탭
- 탭 클릭 시 해당 화면으로 이동하는 라우팅
- 각 화면은 제목 등 최소한의 틀만 표시 (빈 상태)

### 제외
- 예시화면 속 POS자료 업로드, 회계팀 전달자료, 팀장확인, 자료보관함, 기준정보관리 탭
- 홈/일정관리/업무일지 각 화면의 실제 기능(POS 요약, 일정 등록, 업무일지 작성 등) — 이후 별도 기능으로 진행
- 영업부 등 부서별 업무 모듈 — 이후 별도 기능(FEAT-003)으로 진행
