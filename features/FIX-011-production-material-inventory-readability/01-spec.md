# FIX-011: 원재료,반제품 현황 표 가독성 개선

## 문제 상황
FEAT-011로 만든 "원재료,반제품 현황" 화면의 표가 옅은 가로줄만 있는 밋밋한 표라, 같은 성격의 "생산의뢰서" 화면(격자형 테두리 + 헤더 강조 + 숫자 정렬)에 비해 읽기 불편하다.

## 현재 동작
- 헤더가 옅은 배경 없이 좌측 정렬, 열 사이 구분선 없음
- 본문 글자 크기가 작고(text-xs) 숫자 정렬이 오른쪽 정렬만 돼 있어 표 전체가 밋밋함
- 현재고 값이 다른 숫자와 같은 굵기라 한눈에 들어오지 않음

## 기대 동작
- 생산의뢰서 화면과 동일한 격자형 스타일 적용: 헤더 배경(bg-mist/40) + 열 사이 세로 구분선(border-l) + 가운데 정렬 + 숫자는 font-mono
- 본문 글자 크기를 text-sm으로 키워 가독성 향상
- 합계 행은 상단 구분선 + 배경 강조 + 굵게 (생산의뢰서 소계 행과 동일한 톤)
- 현재고 열 값은 데이터 행에서도 굵게 강조

## 영향 범위
- `components/production/ProductionMaterialInventoryView.tsx`의 `InventoryTable` 컴포넌트만 수정, 데이터/로직 변경 없음
