# FIX-018 테스트 케이스

## 정상 케이스

### TC-001: 로그인 쿠키의 Max-Age 확인
**단계:**
1. 로그인한다
2. 아무 페이지나 한 번 더 이동한다(미들웨어가 세션을 갱신하도록)
3. 개발자도구 > Application(또는 저장공간) > 쿠키에서 Supabase 인증 쿠키의 만료(Expires/Max-Age)를 확인한다
**기대 결과:** "세션"으로 표시되고(만료일 없음), 400일 뒤의 날짜가 찍혀있지 않다
**결과:** [ ] 통과 / [ ] 실패

### TC-002: 브라우저 완전 종료 후 로그아웃 확인
**조건:** 브라우저의 "종료 시 마지막 세션 이어서 열기" 옵션이 꺼져 있는 상태
**단계:**
1. 로그인한 채로 페이지를 몇 번 이동한다
2. 브라우저를 완전히 종료했다가 다시 연다
3. 같은 사이트에 접속한다
**기대 결과:** 로그인 화면이 뜬다(자동 로그인되지 않음)
