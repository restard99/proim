# 생산팀 화면 테스트 케이스

## 테스트 전 준비사항
- `production-logs-migration.sql`을 Supabase SQL Editor에서 실행 (아직 안 했다면 필수 — 실행 전에는 생산일지 업로드/조회가 모두 실패합니다)
- 생산팀 팀원 계정 1개, 생산팀 팀장 계정 1개
- 비교용으로 다른 팀 계정 1개(예: 영업채산팀 또는 회계팀, TC-009/010용)
- 실제 생산일지 샘플 엑셀 1개(예: "태평소금 공정별 일일 생산현황_26년 1월.xlsx", 공정별 탭이 여러 개 있는 파일)
- 영업채산팀장 계정으로 미리 생산의뢰서 1건 업로드해둘 것 (TC-003, TC-013용)

## 정상 케이스

### TC-001: 생산팀 팀원 업무일지 작성/제출
**조건:** 생산팀 팀원 계정으로 로그인
**단계:**
1. "업무일지" 메뉴 진입 → 업무 내용 작성 후 저장
**기대 결과:** FEAT-003의 영업부 팀원과 동일하게 정상 작성/제출됨 (별도 개발 없이 재사용된 화면)
**결과:** [ ] 통과 / [ ] 실패

### TC-002: 생산팀장 업무일지 취합 → 상신
**조건:** 생산팀장 계정으로 로그인, 팀원 몇 명이 업무일지를 작성해둔 상태
**단계:**
1. "업무일지" 메뉴 → 업무일지 취합 탭
2. 팀원 내용을 참고해 종합보고서 작성 후 상신
**기대 결과:** 다른 팀장을 경유하지 않고 바로 "상신 완료" 상태가 됨 (생산팀은 최상위 팀)
**결과:** [ ] 통과 / [ ] 실패

### TC-003: 생산팀 계정 — 생산의뢰서(생산계획서) 조회
**조건:** 생산팀 계정(팀원/팀장 무관)으로 로그인, 영업채산팀장이 미리 업로드해둔 생산의뢰서가 있는 상태
**단계:**
1. "생산의뢰서" 메뉴 진입
2. 목록에서 항목 선택
**기대 결과:** 영업채산팀장이 올린 내용이 그대로 조회됨. 업로드 입력창/수정 버튼이 보이지 않음(읽기 전용)
**결과:** [ ] 통과 / [ ] 실패

### TC-004: 생산일지 엑셀 업로드
**조건:** 생산팀 계정(팀원/팀장 무관)으로 로그인
**단계:**
1. "생산일지" 메뉴 진입
2. 왼쪽 업로드 입력에서 샘플 엑셀 선택
**기대 결과:** 업로드 성공 후 목록에 새 항목(기간/파일명/업로더/업로드일시)이 추가되고 자동 선택됨. 오른쪽에 엑셀 안의 공정별 탭이 그대로 나타남
**결과:** [ ] 통과 / [ ] 실패

### TC-005: 공정별 탭 전환
**조건:** TC-004에서 업로드한 생산일지가 선택된 상태
**단계:**
1. 탭을 하나씩 눌러 전환
**기대 결과:** 탭마다 컬럼 구성이 다르게(헤더가 원본 엑셀 3번째 행 그대로) 표시됨
**결과:** [ ] 통과 / [ ] 실패

### TC-006: 시작/종료시간 표시
**조건:** 시작/종료시간 컬럼이 있는 탭 선택
**단계:**
1. 시작시간/종료시간 값 확인
**기대 결과:** "1899.12.30" 같은 날짜 오류 없이 "06:00" 형태로만 표시됨
**결과:** [ ] 통과 / [ ] 실패

### TC-007: 생산일지 삭제 권한
**조건:** 생산팀원 A가 올린 생산일지가 있는 상태
**단계:**
1. A 본인 계정으로 해당 항목 확인 → 삭제 버튼 노출 여부 확인 후 삭제
2. 다른 팀원 B 계정으로 A가 올린(삭제 전) 다른 항목 확인 → 삭제 버튼 노출 여부 확인
3. 관리자(admin) 계정으로 아무 항목이나 확인 → 삭제 버튼 노출 여부 확인
**기대 결과:** 본인이 올린 것과 admin 계정에서만 삭제 버튼이 보이고, 다른 사람 것에는 안 보임
**결과:** [ ] 통과 / [ ] 실패

### TC-008: 원본 파일 열기
**조건:** 생산일지 항목이 선택된 상태
**단계:**
1. "원본 파일 열기" 버튼 클릭
**기대 결과:** 업로드했던 원본 엑셀이 새 탭에서 열리거나 다운로드됨
**결과:** [ ] 통과 / [ ] 실패

### TC-014: 생산효율 탭 — 가동률 집계
**조건:** "총근무시간"·"실근무시간" 컬럼이 있는 생산일지가 1개 이상 업로드된 상태
**단계:**
1. "생산일지" 메뉴 진입 → "생산효율" 모드로 전환
**기대 결과:** 공정별로 가동률(막대바+%)과 정지시간 구성(준비/휴게/청소/고장/기타)이 표시됨. "총근무시간"·"실근무시간" 컬럼이 없는 탭(세척로스율 등)의 데이터는 집계에서 빠져 있어야 함(숫자가 이상하게 섞여 있으면 안 됨)
**결과:** [ ] 통과 / [ ] 실패

### TC-015: 생산효율 탭 — 여러 기간 누적(기본값)
**조건:** 서로 다른 기간의 생산일지가 2개 이상 업로드된 상태
**단계:**
1. "생산효율" 모드 진입 시 기간 드롭다운의 기본 선택 확인
2. 특정 공정의 총근무시간 값 확인
**기대 결과:** 기간 드롭다운이 자동으로 전체 범위(가장 오래된 기간 ~ 가장 최근 기간)로 선택되어 있고, 값도 그 전체 기간이 합산되어 표시됨
**결과:** [ ] 통과 / [ ] 실패

### TC-016: 생산효율 탭 — 기간 좁혀서 조회
**조건:** 서로 다른 기간의 생산일지가 2개 이상 업로드된 상태
**단계:**
1. "생산효율" 모드에서 시작 기간과 종료 기간을 같은 값(예: 최근 1개월)으로 선택
2. 표시되는 값 확인
**기대 결과:** 선택한 한 달치 데이터만 집계되어 전체 기간 값보다 작게(또는 같게) 표시됨
**결과:** [ ] 통과 / [ ] 실패
