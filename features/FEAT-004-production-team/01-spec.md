# 생산팀 화면 기획서

## 개요
생산팀 전용 화면. 영업채산팀·영업팀과 동일한 업무보고 취합·상신 구조를 생산팀에도 적용하고, 영업채산팀장이 올리는 생산계획서(=기존 생산의뢰서 화면)를 생산팀도 조회할 수 있게 한다. 생산팀이 매월 작성하는 생산작업일지(엑셀, 공정별로 탭이 나뉜 실제 샘플 확보됨)를 업로드하고 탭별로 조회할 수 있는 화면도 추가한다.

## 사용자
생산팀 소속 직원 — 생산팀 팀원/팀장

## 해결하는 문제
- 생산팀도 영업부처럼 일일업무보고를 정형화된 도구 없이 구두/메신저로 처리하고 있다
- 영업채산팀장이 올리는 생산계획서(엑셀)를 생산팀이 실시간으로 확인할 방법이 없다
- 생산작업일지(생산팀이 작성하는 실제 생산 실적 기록, 공정별 엑셀)를 올릴 곳이 없다 — 실제 샘플(`태평소금 공정별 일일 생산현황_26년 1월.xlsx`, 탭 5개: 가공및선별공정/포장공정/3공장/세척로스율/포장공정(로스율측정자료), 탭마다 컬럼 구성이 다름)을 확보해 이번 범위에 포함

## 기대 효과
- 생산팀원은 업무일지를 작성해 제출한다 (FEAT-003과 동일한 화면/구조 재사용)
- 생산팀장은 팀원 보고를 취합해 종합 보고서로 재정리한 뒤 상신한다. 생산팀은 최상위 팀이라 영업채산팀처럼 다른 팀장을 경유하지 않고 상신으로 마무리된다 (사장님 수신함 화면은 이번 범위 밖 — FEAT-003과 동일한 제약)
- 생산팀은 영업채산팀장이 업로드한 생산계획서(기존 `/production-requests` 화면, 엑셀 업로드→BOM 부자재 현황 표시)를 그대로 조회할 수 있다. 업로드·수정 권한은 기존과 동일하게 영업채산팀장/관리자만 유지하고, 생산팀은 읽기 전용으로 접근한다
- 생산팀 팀원(팀장 포함)은 누구나 "생산효율" 탭 하단에서 생산작업일지 엑셀을 업로드할 수 있다. 업로드하면 엑셀 안의 공정별 탭(가공및선별공정/포장공정/3공장/세척로스율/포장공정(로스율측정자료))이 화면에서도 탭으로 그대로 재현되고, 탭을 선택하면 해당 공정의 표를 볼 수 있다
  - 탭마다 컬럼 구성이 서로 달라 특정 컬럼을 고정해서 다루지 않고, 각 탭의 3번째 행(헤더)을 표 헤더로, 4번째 행부터를 데이터 행으로 동적으로 인식해 그대로 표로 그린다 (엑셀 양식이 달마다 조금씩 바뀌어도 코드 수정 없이 대응)
  - 생산의뢰서와 달리 부자재 재고 매칭 등 추가 계산은 하지 않고, 업로드된 데이터를 있는 그대로 조회하는 용도다
  - 파일을 선택하면 원본 표를 보여주기 전에 그 파일만의 요약 카드(참여 공정 수/가동률/총 정지시간/인당 투입량)를 먼저 보여줘서, 표를 훑지 않아도 전체 상황이 한눈에 들어오게 한다 (사용자 피드백: "생산일지 작업해준건 전체상황이 한눈에 들어오지도 않고 어떤지 알수가 없네")
- "생산효율" 탭에서 업로드된 생산일지 중 조회할 **기간(시작~종료 월)을 선택**하면, 그 범위에 해당하는 생산일지를 대상으로 "총근무시간"·"실근무시간" 컬럼이 있는 시트를 찾아 공정별로 합산해 **가동률**(실근무시간÷총근무시간)과 정지시간 구성(준비/휴게/청소/고장/기타)을 보여준다. 생산팀이 이 화면만 보고 어느 공정의 가동률이 낮은지, 정지 원인이 무엇인지, 기간별로 어떻게 달라지는지 바로 파악할 수 있게 하는 것이 목적. 생산일지 업로드/목록/원본 조회 기능도 이 탭 하단에 함께 있다 (별도 "생산일지 조회" 탭으로 나누지 않음)
- "인당생산성" 탭은 스냅샷이 아니라 **기간(월)별 흐름**을 보여준다. 선택한 기간 범위 안의 각 월을 오래된 순서로 나열해 가동률·투입인원(연인원)·투입량 합계·인당 투입량이 달마다 어떻게 변해왔는지 한눈에 훑을 수 있게 한다(사용자 피드백: "인당생산성 탭에는 전체적으로 어떤흐름으로 생산이 되고 있는지 알 수 있었으면 좋겠어"). 생산일지의 "투입량"·"투입인원" 컬럼을 근거로 계산하는 근사 지표로, 완제품 생산량(kg)·정규 인원 기준의 인사 리포트와는 산출 기준이 다르다는 점을 화면에 명시한다

## 범위
### 포함
- 생산팀 팀원용 일일업무보고 작성/제출 (FEAT-003 컴포넌트 재사용, 신규 개발 최소화)
- 생산팀장용 팀원 보고 취합 + 종합 보고서 작성/상신 (사장님에게 직접, 경유 없음)
- 기존 `/production-requests`(생산계획서) 화면에 생산팀 조회 권한 추가 — 단, `/inventory`(재고현황) 접근권은 별도로 부여하지 않음
- "생산효율" 탭 신설 — 기간(시작~종료 월) 선택 후 그 범위의 생산일지를 집계해 공정별 가동률 + 정지시간 구성을 보여줌. 생산일지 엑셀 업로드(생산팀 팀원 누구나 가능)/목록/파일별 요약 카드/원본 표 조회도 이 탭 안에 포함
- "인당생산성" 탭 신설 — 기간(월)별 가동률/투입인원/투입량/인당 투입량 흐름을 오래된 순으로 보여주는 시계열 리스트
- 생산팀 전용 사이드바 메뉴 노출 (업무일지는 기존과 동일, 생산계획서·생산일지 메뉴 항목 추가)

### 제외
- 생산계획서 신규 업로드/작성 기능 — 생산팀은 업로드하지 않고 조회만 함 (업로드는 기존 영업채산팀장 화면 그대로 사용)
- 생산일지 원본 표(공정별 탭)에 대한 추가 계산 — 가동률/정지시간 집계(생산효율 탭)를 제외한 로스율 자동 검증, 부자재 매칭 등은 계속 범위 밖
- 재고현황(`/inventory`) 화면 접근 — 이번 범위 아님
- 사장님이 최종 상신된 보고를 확인하는 수신함 화면 — FEAT-003과 동일하게 제외
- 정식 전자결재(승인/반려, 결재선 지정) 기능
