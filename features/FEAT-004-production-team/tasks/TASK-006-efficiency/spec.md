# TASK-006: 생산효율(가동률) 탭

## 목적
업로드된 생산일지를 기간(시작~종료 월) 선택해 집계할 수 있는 공정별 가동률(실근무시간÷총근무시간)과 정지시간 구성(준비/휴게/청소/고장/기타) 탭을 추가한다.

## 작업 범위
- 수정할 파일: `app/actions/production-logs.ts` (`getProductionEfficiency`, `getProductionLogPeriods` 추가), `components/production/ProductionLogView.tsx` (모드 토글 + 기간 선택 + 가동률 표 렌더링)

## 완료 기준
- [ ] "총근무시간"·"실근무시간" 컬럼이 모두 있는 시트만 집계 대상으로 삼음
- [ ] 공정명 컬럼이 있으면 공정명 기준, 없으면 시트 이름 기준으로 그룹핑
- [ ] 총근무시간/실근무시간/정지시간/준비/휴게/청소/고장/기타 합산, 가동률(%) 계산
- [ ] 시작 기간~종료 기간 드롭다운으로 범위를 좁혀 집계 가능 (기본값: 전체 기간)
- [ ] "생산일지 조회"/"생산효율" 모드 토글 UI
- [ ] 생산효율 모드: 공정별 가동률 막대바 + % 표, 정지시간 구성 표시
- [ ] 데이터 없음(생산일지 자체가 없음 / 선택 기간에 집계 대상 시트가 없음) 상태 문구
