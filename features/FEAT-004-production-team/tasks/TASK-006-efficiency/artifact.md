# TASK-006: 생산효율(가동률) 탭 — 아티팩트

## 상태: 완료 (DB 미적용 상태라 런타임 미검증)

## 구현 내용
업로드된 생산일지를 기간(시작~종료 월) 선택해 집계할 수 있는 공정별 가동률과 정지시간 구성을 보여주는 "생산효율" 모드를 추가했다. "총근무시간"·"실근무시간" 컬럼이 모두 있는 시트만 집계 대상으로 삼아, 세척로스율 등 근무시간 데이터가 없는 탭은 자동으로 제외된다. 최초 구현은 전체 기간 누적만 지원했으나, 사용자 피드백("기간을 통해서 효율을 검토할 수 있도록")을 받아 기간 범위 선택 기능을 추가했다.

## 생성/수정된 파일
- `app/actions/production-logs.ts`: `getProductionEfficiency(startPeriod?, endPeriod?)` — 기간 범위로 필터링해 공정별(또는 시트명 기준)로 총근무/실근무/정지/준비/휴게/청소/고장/기타 시간을 합산, 가동률(%) 계산. `getProductionLogPeriods()` — 존재하는 period_label 목록(오래된 순). `periodSortKey()` — "YYYY년 M월" 형식을 정수로 변환해 범위 비교
- `components/production/ProductionLogView.tsx`: "생산일지 조회"/"생산효율" 모드 토글 추가, `EfficiencyView` 컴포넌트(기간 선택 드롭다운 2개 + 가동률 막대바 + 정지시간 구성 표)

## 완료 기준 확인
- [x] "총근무시간"·"실근무시간" 컬럼 모두 있는 시트만 집계
- [x] 공정명 컬럼 있으면 공정명 기준, 없으면 시트 이름 기준 그룹핑
- [x] 8개 컬럼 합산 + 가동률 계산
- [x] 시작~종료 기간 드롭다운으로 범위 선택 (기본값: 전체 기간)
- [x] 모드 토글 UI
- [x] 가동률 막대바 + % 표시
- [x] 데이터 없음 상태 문구 (생산일지 없음 / 선택 기간 내 집계 대상 없음 구분)

## 이슈 및 결정사항
DB 마이그레이션(TASK-001)이 아직 적용되지 않아 실제 데이터로는 검증하지 못했다. 컬럼명이 정확히 일치해야("총근무시간", "실근무시간" 등) 집계되므로, 원본 엑셀 헤더 문구가 달라지면 그 시트는 조용히 집계에서 빠진다 — 이는 "그럴듯하게 틀린 집계"보다 안전하다는 기존 설계 원칙과 동일하게 의도적으로 선택한 동작이다.
