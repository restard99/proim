# TASK-002: 생산일지 엑셀 파싱 — 아티팩트

## 상태: 배포 완료

## 구현 내용
워크북의 모든 시트를 순회하며 3번째 행을 헤더, 4번째 행부터를 데이터로 인식해 `{ name, headers, rows }[]`로 반환하는 파서를 만들었다. 시작/종료시간처럼 시간 전용 셀이 Excel 날짜 기준일(1899-12-30/31)로 잘못 해석된 경우 `HH:mm`만 남기도록 처리했다. 합성 워크북으로 직접 스모크 테스트해 시간 포맷팅, 빈 행 스킵, 헤더 없는 빈 시트 처리를 확인했다.

## 생성/수정된 파일
- `lib/production-logs/parse.ts`: `parseProductionLogWorkbook(buffer)` — 시트별 헤더/데이터 동적 파싱, 중복 헤더 명 자동 구분(`열N`, `(2)` 접미사)

## 완료 기준 확인
- [x] 모든 시트를 `{ name, headers, rows }`로 변환
- [x] 3번째 행 헤더 / 4번째 행부터 데이터
- [x] 시간 전용 셀 `HH:mm` 포맷 처리 (스모크 테스트로 검증)
- [x] 빈 행 스킵
- [x] 헤더 없는 시트는 빈 rows로 처리, 에러 없이 다음 시트 계속 처리

## 이슈 및 결정사항
헤더가 비어있는 컬럼은 `열N`으로 대체해 원본 컬럼 위치를 그대로 보존한다(예: 테두리용 빈 첫 컬럼). 같은 헤더명이 반복되면 `(2)`, `(3)` 접미사를 붙여 구분한다.
