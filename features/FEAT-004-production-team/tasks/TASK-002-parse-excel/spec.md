# TASK-002: 생산일지 엑셀 파싱

## 목적
공정별로 탭이 나뉜 생산작업일지 엑셀을 업로드했을 때, 탭 구성/컬럼이 매달 조금씩 바뀌어도 코드 수정 없이 그대로 반영되도록 워크북 전체 시트를 동적으로 파싱한다.

## 작업 범위
- 생성할 파일: `lib/production-logs/parse.ts`

## 완료 기준
- [ ] 워크북의 모든 시트를 순회하며 각 시트를 `{ name, headers, rows }`로 변환
- [ ] 3번째 행을 헤더로, 4번째 행부터를 데이터 행으로 인식 (고정 컬럼 타입 없이 헤더를 그대로 신뢰)
- [ ] 시작/종료시간 등 시간 전용 셀이 Excel 기준일(1899-12-30)로 잘못 해석되는 경우를 감지해 `HH:mm`으로만 포맷
- [ ] 완전히 빈 행은 건너뜀
- [ ] 헤더 행이 없거나(3번째 행이 비어있는 시트) 데이터가 없는 시트는 빈 rows로 처리하고 에러를 던지지 않음(다른 정상 시트는 그대로 반환)
