# 거래처별 매출 엑셀 내보내기 테스트 케이스

## 테스트 전 준비사항
- 거래처별 매출 화면 조회 권한이 있는 계정으로 로그인
- 좌측 메뉴에서 "거래처별 매출" 진입
- 로컬 개발 서버 실행 중

## 정상 케이스

### TC-001: 주간 탭 다운로드
**단계:**
1. "주간" 탭에서 데이터가 있는 주차로 조회
2. "엑셀 다운로드" 클릭
**기대 결과:** `거래처별매출_주간_{시작일}_{종료일}.xlsx` 파일이 다운로드된다. 상단에 그룹 요약표, 하단에 그룹별 지점명/금액/최근거래일 상세가 들어있고 제품 내역은 없다.
**결과:** [ ] 통과 / [ ] 실패

### TC-002: 월간/월누적 탭 다운로드
**단계:**
1. "월간" 또는 "월누적" 탭에서 데이터가 있는 기간으로 조회 후 다운로드
**기대 결과:** 하단 상세에 업체별 합계 행과 그 아래 제품명/수량/금액 행까지 포함된다.
**결과:** [ ] 통과 / [ ] 실패

### TC-003: 검색어 적용 상태에서 다운로드
**단계:**
1. 거래처 검색창에 특정 거래처명 입력 후 조회
2. 다운로드
**기대 결과:** 엑셀에도 필터링된 거래처만 포함된다.
**결과:** [ ] 통과 / [ ] 실패
