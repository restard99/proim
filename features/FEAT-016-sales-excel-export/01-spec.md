# 거래처별 매출 엑셀 내보내기 기획서

## 개요
거래처별 매출(FEAT-004/FEAT-014) 화면의 주간/월간/월누적 탭에서, 현재 조회조건(탭·기간·검색어)의 거래처별 매출 요약과 전체 상세내역을 엑셀 파일로 내보낼 수 있게 한다.

## 사용자
영업팀/영업채산팀 등 거래처별 매출 화면 조회 권한이 있는 사용자

## 해결하는 문제
화면에서는 그룹(이마트/롯데 등 브랜드 단위)을 하나씩 클릭해야 지점별 금액이나 업체별 제품 내역을 볼 수 있어, 전체 내용을 한 번에 보거나 다른 곳에 공유·보관하기 어렵다.

## 기대 효과
- 화면에서 보던 것과 동일한 조건(탭·기간·검색어)으로 엑셀 파일을 바로 받을 수 있다
- 엑셀 한 시트 안에 거래처(그룹) 요약표와, 그 아래 전체 상세내역이 함께 들어있어 따로 클릭해볼 필요가 없다

## 범위
### 포함
- 화면에 "엑셀 다운로드" 버튼 추가
- 대상 탭: 주간 / 월간 / 월누적 (연간목표대비 탭은 제외 — 목표 대비 진행률 그래프라 구조가 다름)
- 내보내는 범위: 현재 선택된 탭 + 현재 조회기간 + 현재 검색어 조건 그대로
- 엑셀 구성(한 시트):
  1. 상단: 거래처(그룹) 요약표 — 화면의 목록과 동일 (거래처 / 매출액 / 최근 거래일)
  2. 하단: 전체 그룹/거래처의 상세내역을 이어서 나열
     - 주간: 그룹별 지점명 + 금액 + 최근거래일 (화면의 지점 펼치기와 동일 수준)
     - 월간/월누적: 그룹/거래처별로 업체명 구분행 + 업체별 제품명/수량/금액 (화면의 제품 펼치기와 동일 수준)
- 파일명에 탭 이름과 조회기간 포함

### 제외
- 연간목표대비 탭 내보내기
- 엑셀 서식 꾸미기 고도화
- 엑셀 업로드/가져오기 기능
