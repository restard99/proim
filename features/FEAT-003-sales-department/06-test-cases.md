# 영업부 화면 테스트 케이스

## 테스트 전 준비사항
- `lib/supabase/schema.sql`, `lib/supabase/seed.sql`의 FEAT-003 섹션이 Supabase 대시보드에 이미 적용되어 있어야 함
- 다음 승인 완료 계정이 필요함:
  - 영업채산팀 팀원 1명 이상 (`role = member`)
  - 영업채산팀 팀장 1명 (`role = leader`)
  - 영업팀 팀원 1명 이상 (`role = member`)
  - 영업팀 팀장 1명 (`role = leader`)
  - 영업부 외 다른 팀 계정 1개 (예: 회계팀, TC-011/012용)
- `.env.local`(또는 Vercel 환경변수)에 Y-ERP 접속 정보(`MSSQL_*`)가 설정되어 있어야 거래처별 매출/수금현황이 실제 데이터로 조회됨

## 정상 케이스

### TC-001: 팀원 업무일지 작성/제출
**조건:** 영업채산팀(또는 영업팀) 팀원 계정으로 로그인
**단계:**
1. 사이드바 "업무일지" 클릭
2. 오늘 방문한 거래처, 주요 업무 내용, 특이사항을 입력
3. "제출하기" 클릭
**기대 결과:** 상단 상태 배지가 "제출완료"로 바뀌고, 좌측 "최근 제출 내역"에 오늘 날짜 항목이 추가됨
**결과:** [ ] 통과 / [ ] 실패

### TC-002: 최근 제출 내역 검색 및 수정
**조건:** TC-001에서 최소 1건 이상 제출한 상태
**단계:**
1. 좌측 검색창에 방문 거래처명 또는 날짜 일부를 입력
2. 검색된 항목 클릭(또는 "수정" 클릭)
**기대 결과:** 해당 날짜의 내용이 우측 폼에 그대로 불러와지고, 수정 후 다시 저장할 수 있음
**결과:** [ ] 통과 / [ ] 실패

### TC-003: 팀장 업무일지 작성 탭
**조건:** 영업채산팀장 계정으로 로그인
**단계:**
1. 사이드바 "업무일지" 클릭 → 상단 "업무일지 작성" 탭 선택
2. 오늘 업무 내용 작성 후 저장
**기대 결과:** 팀원 화면과 동일한 폼이 보이고, 버튼 문구가 "저장하기"로 표시됨 (제출하기 아님)
**결과:** [ ] 통과 / [ ] 실패

### TC-004: 영업채산팀장 취합 및 상신
**조건:** 영업채산팀 팀원이 TC-001로 오늘 업무일지를 제출해둔 상태, 영업채산팀장으로 로그인
**단계:**
1. "업무일지 취합" 탭에서 좌측 팀원 이름 클릭
2. 가운데 패널에 뜬 최근 1주 내역에서 날짜를 펼치고, 필요한 줄만 체크
3. "선택한 내용 종합보고서에 추가" 클릭
4. 우측 종합보고서 내용을 정리한 뒤 "영업팀장에게 상신" 클릭
**기대 결과:** 체크한 줄만 우측 편집기에 추가되고, 상신 후 상태가 "상신완료"로 바뀜
**결과:** [ ] 통과 / [ ] 실패

### TC-005: 영업팀장 최종 상신
**조건:** TC-004로 영업채산팀장이 상신 완료한 상태, 영업팀장으로 로그인
**단계:**
1. "업무일지 취합" 탭에서 좌측 목록에 "한소연(영업채산팀장)"이 상신완료 상태로 보이는지 확인
2. 이름 클릭 → 가운데 패널에서 영업채산팀 상신 내용 확인
3. 내용을 종합보고서에 반영 후 "사장님에게 최종 상신" 클릭
**기대 결과:** 좌측 목록에 영업채산팀장이 포함되어 있고, 상신 문구가 "사장님에게 최종 상신됩니다"로 표시됨
**결과:** [ ] 통과 / [ ] 실패

### TC-006: 거래처별 매출 · 주간 조회
**조건:** 영업팀/영업채산팀 계정으로 로그인
**단계:**
1. 사이드바 "거래처별 매출" 클릭 (기본 "주간" 탭)
2. ◀/▶ 버튼으로 이전/다음 주 이동
**기대 결과:** 주 단위 날짜 범위가 바뀌고, 표와 합계 카드 값이 실제 Y-ERP 데이터로 갱신됨
**결과:** [ ] 통과 / [ ] 실패

### TC-007: 거래처별 매출 · 월간/월누적/비교기준
**단계:**
1. "월간", "월누적" 탭을 각각 클릭해 데이터 확인
2. "비교 기준"을 전주/전월/전년 동기로 바꿔가며 카드 값 변화 확인
**기대 결과:** 탭 전환 시마다 해당 기간 데이터로 갱신되고, 비교 기준 변경 시 증감률이 다시 계산됨
**결과:** [ ] 통과 / [ ] 실패

### TC-008: 거래처별 매출 · 연간목표대비
**단계:**
1. "연간목표대비" 탭 클릭
**기대 결과:** `sales_targets`에 목표가 등록되어 있지 않다면 "목표가 아직 설정되지 않았습니다" 안내와 누적 매출이 표시됨 (목표가 있다면 진행률 바가 표시됨)
**결과:** [ ] 통과 / [ ] 실패

### TC-009: 수금현황 조회
**단계:**
1. 사이드바 "수금현황" 클릭
2. 기준월을 지난달로 변경, 거래처명으로 검색
**기대 결과:** 요약 카드(이 달 수금액/미수금 잔액/미수 거래처)와 표가 선택한 월 기준으로 갱신되고 검색이 동작함
**결과:** [ ] 통과 / [ ] 실패

### TC-010: 영업부 메뉴 노출
**조건:** 영업팀 또는 영업채산팀 계정으로 로그인
**단계:**
1. 사이드바 확인
**기대 결과:** "영업부" 섹션(거래처별 매출, 수금현황)이 보임
