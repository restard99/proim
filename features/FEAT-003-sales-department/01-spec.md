# 영업부 화면 기획서

## 개요
영업부(영업팀·영업채산팀) 전용 화면. 팀원이 작성한 일일업무보고를 팀장이 취합·보완해 상위 보고자에게 상신하는 흐름을 지원하고, Y-ERP(SMARTE_DB)의 거래처별 매출·수금현황을 읽기 전용으로 조회할 수 있게 한다.

## 사용자
영업부 소속 직원 — 영업팀 팀원/팀장, 영업채산팀 팀원/팀장

## 해결하는 문제
- 일일업무보고를 팀원 각자 작성 → 팀장이 종합 → 위로 전달하는 과정이 정형화된 도구 없이(구두, 메신저 등) 이뤄지고 있다
- 거래처별 매출, 수금현황을 확인하려면 매번 Y-ERP를 직접 열어 조회해야 해서 번거롭다

## 기대 효과
- 팀원은 이 화면에서 일일업무보고를 작성해 제출한다
- 팀장은 팀원들이 제출한 보고를 모아서 보고, 그 내용을 자유롭게 수정·재구성해 하나의 팀 종합 보고서로 다시 정리한 뒤 상신한다 (팀원 원본을 그대로 붙이는 게 아니라 팀장이 직접 고쳐 쓸 수 있어야 함)
  - 영업채산팀장이 상신하면 **영업팀장에게** 전달된다. 영업팀장은 이를 자신의 보고에 "영업채산팀" 구분 섹션으로 포함시켜 최종 상신한다 (영업부 내용과 영업채산팀 내용이 섞이지 않고 구분되어야 함)
  - 그 외 팀은 팀장이 상신하면 사장님에게 바로 전달되는 것이 원칙이나, 이번 범위는 영업부만 다룬다
- 거래처별 매출, 수금현황을 Y-ERP(SMARTE_DB)에서 읽기 전용으로 조회해 화면에서 바로 확인할 수 있다

## 범위
### 포함
- 팀원용 일일업무보고 작성/제출
- 팀장용: 팀원 보고 취합 화면 + 종합 보고서 작성/상신
- 영업채산팀 → 영업팀장 경유 상신 흐름 (팀별 구분 유지)
- 거래처별 매출 조회 (Y-ERP `PM_IO_DAILY_CUST` 기반, 읽기 전용)
- 수금현황 조회 (Y-ERP `PM_RCB_COLLECT_MGMT` / `PM_RCB_COLLECT_DTL` 기반, 읽기 전용)

### 제외
- Y-ERP에 데이터를 쓰거나 수정하는 기능 — 조회만 지원 (읽기 전용 계정)
- 사장님이 최종 상신된 보고를 확인하는 화면(수신함) — 이번 범위는 "상신"까지, 수신 화면은 별도 기능으로 진행
- 영업부 외 다른 부서의 일일업무보고 워크플로우 — 이번엔 영업부만, 원칙은 동일하게 추후 확장 가능하도록 설계는 해두되 다른 부서 화면 구현은 하지 않음
- 정식 전자결재(승인/반려, 결재선 지정) 기능 — 이번엔 단순 취합→상신까지만
