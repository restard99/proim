# 비밀번호 찾기/변경 기획서

## 개요
비밀번호를 잊었을 때 스스로 이메일로 재설정할 수 있게 하고, 로그인된 상태에서도 스스로 비밀번호를 바꿀 수 있게 한다. 이메일이 없거나 메일 수신이 안 되는 계정은 관리자가 화면에서 대신 재설정해줄 수 있게 한다.

## 사용자
- 전 직원(팀원/팀장): 비밀번호 찾기, 로그인 상태에서 비밀번호 변경
- 관리자: 특정 사용자의 비밀번호 대리 재설정

## 해결하는 문제
- 비밀번호를 잊으면 로그인 자체가 안 되는데 스스로 해결할 방법이 전혀 없다
- 지금 일반 직원 계정은 가입 시 실제로 존재하지 않는 가짜 이메일(`@internal.taepyeong.invalid`)로 만들어져서, Supabase의 표준 "이메일로 재설정 링크 발송" 기능이 관리자 계정 말고는 아무에게도 통하지 않는다
- 설령 이메일이 있다 해도, 재설정 메일의 링크를 눌렀을 때 새 비밀번호를 입력받을 화면이 앱에 없어서 그냥 로그인 화면으로 떨어진다 (실제로 겪은 문제)

## 기대 효과
- 회원가입 화면에 이메일 입력란이 추가되고, 그 이메일이 실제 로그인 인증 이메일로 사용된다 (기존의 가짜 이메일 방식 폐기, 신규 가입자부터 적용)
- 로그인 화면에 "비밀번호 찾기" 링크가 생긴다. 들어가서 이름+소속팀만 입력하고 "비밀번호 리셋" 버튼을 누르면, 등록된 이메일로 재설정 링크가 발송된다 (계정 존재 여부를 노출하지 않기 위해 결과 메시지는 항상 동일하게 안내)
- 메일의 링크를 누르면 앱 안에서 바로 새 비밀번호를 입력하는 화면으로 연결된다
- 이메일이 등록되지 않은 기존 계정이거나 메일이 오지 않는 경우, 관리자가 관리자 화면에서 해당 사용자를 찾아 새 비밀번호를 직접 지정해줄 수 있다
- 로그인된 상태에서 스스로 비밀번호를 바꾸고 싶을 때 쓰는 "내 정보" 화면이 생긴다 (현재 비밀번호 확인 후 변경)

## 범위
### 포함
- 회원가입 폼에 이메일 입력란 추가 (필수) — 이후 이 이메일이 Supabase 인증 이메일로 사용됨
- "비밀번호 찾기" 페이지 (로그인 화면 옆 링크로 진입): 이름+소속팀 입력 → "비밀번호 리셋" 버튼
- 메일의 재설정 링크를 받아 새 비밀번호를 입력하는 페이지
- 관리자 화면(기존 가입승인 화면 확장)에 사용자별 "비밀번호 재설정" 기능 추가
- 로그인 상태에서 스스로 비밀번호를 바꾸는 "내 정보" 화면

### 제외
- 가입 확인 이메일(이메일 인증) — 기존처럼 비활성 상태 유지, 이메일은 재설정 용도로만 사용
- 기존에 이미 가입되어 있던 계정들에 이메일을 일괄로 채워 넣는 작업 — 필요하면 각 사용자가 관리자에게 요청해 대리 재설정으로 해결
- 아이디(이름) 자체를 잊어버린 경우의 찾기 기능
- 2단계 인증 등 추가 보안 기능

## 참고 — 운영상 필요한 사전 설정
Supabase 프로젝트의 기본 이메일 발송 기능은 시간당 발송량 제한이 낮습니다(커스텀 SMTP 미설정 시). 재설정 메일이 잘 안 온다면 Supabase 대시보드 → Authentication → Settings → SMTP Settings에서 실제 메일 발송 서비스(네이버웍스, Gmail SMTP 등)를 연결해야 할 수 있습니다. 3단계에서 다시 안내합니다.
