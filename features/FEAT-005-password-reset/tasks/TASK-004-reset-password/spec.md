# TASK-004: 새 비밀번호 설정 페이지

## 목적
이메일의 재설정 링크를 눌렀을 때 도착하는 `/reset-password` 페이지를 만든다. 지금은 이 경로가 없어서 링크를 눌러도 로그인 화면으로 떨어지는 문제가 실제로 있었다.

## 작업 범위
- 생성할 파일:
  - `app/reset-password/page.tsx`
  - `components/auth/ResetPasswordForm.tsx` (클라이언트 컴포넌트 — Supabase 브라우저 클라이언트로 recovery 세션 확인)
- 수정할 파일: `app/actions/auth.ts` 또는 클라이언트에서 직접 — 새 비밀번호 저장은 `supabase.auth.updateUser({ password })` (recovery 세션이 필요하므로 서버 액션이 아니라 브라우저 클라이언트에서 처리)

## 완료 기준
- [ ] 유효한 재설정 링크로 접속하면 새 비밀번호 입력 폼이 보인다
- [ ] 새 비밀번호를 2회 입력해 제출하면 비밀번호가 변경되고 "변경 완료" 안내 후 로그인 화면으로 이동할 수 있다
- [ ] 변경된 새 비밀번호로 실제 로그인이 된다
- [ ] recovery 세션이 없는 상태(직접 `/reset-password` 접속, 만료된 링크)로 들어오면 "링크가 만료되었습니다" 안내와 "비밀번호 찾기 다시 하기" 버튼이 보인다
- [ ] 8자 미만 등 비밀번호 형식 오류 시 검증 메시지가 뜬다
