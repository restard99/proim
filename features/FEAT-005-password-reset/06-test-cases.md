# 비밀번호 찾기/변경 테스트 케이스

## 테스트 전 준비사항
- 개발 서버가 실행 중이어야 합니다 (`http://localhost:3000`)
- Supabase 대시보드 → Authentication → URL Configuration → Redirect URLs에 `http://localhost:3000/reset-password`가 등록되어 있어야 합니다 (등록 안 되어 있으면 TC-004가 실패합니다)
- 관리자 계정(role=admin)과, 테스트용으로 새로 가입시킬 신규 계정 하나가 필요합니다
- 이메일 수신함(신규 가입 시 입력한 실제 메일 주소)에 접근 가능해야 합니다

## 정상 케이스

### TC-001: 회원가입 시 이메일 입력
**조건:** 로그아웃 상태
**단계:**
1. `/signup` 접속
2. 이름, 소속팀, 실제 수신 가능한 이메일, 비밀번호를 입력하고 가입
**기대 결과:** 가입이 완료되고 "승인 대기" 안내가 표시된다 (또는 기존 가입 흐름과 동일)
**결과:** [ ] 통과 / [ ] 실패

### TC-002: 이메일 중복 가입 시도
**조건:** TC-001에서 사용한 이메일이 이미 등록됨
**단계:**
1. `/signup`에서 동일한 이메일로 다시 가입 시도
**기대 결과:** "이미 등록된 이메일" 등 중복 안내 메시지가 표시되고 가입되지 않는다
**결과:** [ ] 통과 / [ ] 실패

### TC-003: 비밀번호 찾기 요청
**조건:** TC-001의 계정이 관리자 승인까지 완료된 상태 (또는 승인 여부 무관하게 계정만 존재)
**단계:**
1. `/login`에서 "비밀번호 찾기" 링크 클릭
2. 이름과 소속팀을 정확히 입력
3. "비밀번호 리셋" 버튼 클릭
**기대 결과:** "요청을 처리했습니다" 등 동일한 안내 문구가 표시되고, 등록된 이메일로 재설정 링크 메일이 도착한다
**결과:** [ ] 통과 / [ ] 실패

### TC-004: 재설정 링크로 새 비밀번호 설정
**조건:** TC-003에서 받은 메일이 있음
**단계:**
1. 메일의 재설정 링크 클릭
2. `/reset-password` 화면에서 새 비밀번호를 2회 입력
3. 제출
**기대 결과:** 로그인 화면으로 돌아가지 않고 새 비밀번호 입력 화면이 바로 뜬다. 제출 후 "변경 완료" 안내가 표시된다
**결과:** [ ] 통과 / [ ] 실패

### TC-005: 새 비밀번호로 로그인
**조건:** TC-004 완료
**단계:**
1. `/login`에서 새로 설정한 비밀번호로 로그인
**기대 결과:** 정상 로그인된다
**결과:** [ ] 통과 / [ ] 실패

### TC-006: 로그인 상태에서 스스로 비밀번호 변경
**조건:** 로그인된 상태
**단계:**
1. 사이드바 하단 프로필(이름/소속팀) 클릭 → `/account` 진입
2. 현재 비밀번호, 새 비밀번호, 새 비밀번호 확인 입력 후 "비밀번호 변경" 클릭
**기대 결과:** "변경되었습니다" 안내가 표시된다
**결과:** [ ] 통과 / [ ] 실패

### TC-007: 변경한 비밀번호로 재로그인
**조건:** TC-006 완료
**단계:**
1. 로그아웃 후 새 비밀번호로 로그인
**기대 결과:** 정상 로그인된다
**결과:** [ ] 통과 / [ ] 실패

### TC-008: 관리자 대리 비밀번호 재설정
**조건:** 관리자 계정으로 로그인
**단계:**
1. `/admin/approvals` 접속 → "전체 사용자" 섹션 확인
2. 임의 사용자를 검색으로 찾은 뒤 "비밀번호 재설정" 클릭
3. 모달에 표시된 임시 비밀번호를 복사
**기대 결과:** 이메일이 없는 계정(가짜 도메인)은 "미등록"으로 표시되고, 임시 비밀번호가 모달에 1회 노출된다
**결과:** [ ] 통과 / [ ] 실패

### TC-009: 발급된 임시 비밀번호로 로그인
**조건:** TC-008 완료
**단계:**
1. 해당 사용자 계정으로 로그아웃 후 임시 비밀번호로 로그인 시도
**기대 결과:** 정상 로그인된다
**결과:** [ ] 통과 / [ ] 실패

## 예외 케이스

### TC-010: 잘못된 이름/소속팀으로 비밀번호 찾기
**조건:** 로그아웃 상태
**단계:**
1. `/forgot-password`에서 존재하지 않는 이름+소속팀 입력 후 제출
**기대 결과:** 계정이 없다는 사실이 드러나지 않고, TC-003과 동일한 "요청을 처리했습니다" 문구가 표시된다 (메일은 당연히 오지 않음)
**결과:** [ ] 통과 / [ ] 실패

### TC-011: 만료되거나 이미 사용한 재설정 링크
**조건:** TC-004에서 이미 사용한 링크, 또는 오래된 링크
**단계:**
1. 이미 사용했던 재설정 링크를 다시 클릭
**기대 결과:** "링크가 만료되었습니다" 등 오류 상태가 표시되고, 새 비밀번호 입력 폼은 뜨지 않는다
**결과:** [ ] 통과 / [ ] 실패

### TC-012: 현재 비밀번호를 잘못 입력하고 변경 시도
**조건:** `/account`에 로그인 상태로 진입
**단계:**
1. 현재 비밀번호란에 틀린 값을 입력하고 새 비밀번호 입력 후 제출
**기대 결과:** "현재 비밀번호가 올바르지 않습니다" 오류가 표시되고 비밀번호는 변경되지 않는다
**결과:** [ ] 통과 / [ ] 실패

**조건:** 일반 직원 계정으로 로그인
**단계:**
1. 주소창에 `/admin/approvals`를 직접 입력해 접근 시도
**기대 결과:** 홈(`/`)으로 리다이렉트되고 "전체 사용자" 목록이 보이지 않는다

**기대 결과:** "비밀번호가 일치하지 않습니다" 검증 오류가 표시되고 제출되지 않는다
