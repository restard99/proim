# FIX-004: 관리자 사이드바 업무 메뉴에 소속팀 배지 표기

## 문제 상황
관리자 계정으로 로그인하면 모든 팀의 업무 메뉴(거래처별 매출, 수금현황, 재고현황, 생산의뢰서, 생산일지, 생산량, 부자재재고현황 등)가 하나의 섹션에 뒤섞여 나열된다. 어떤 메뉴가 어느 팀 소속인지 라벨만으로는 구분하기 어렵다.

## 현재 동작
사이드바에서 관리자에게 보이는 업무 메뉴는 팀 구분 없이 아이콘 + 라벨만 표시된다.

## 기대 동작
관리자 화면에서 각 업무 메뉴 항목 오른쪽에 소속팀명을 어두운 톤(회색조)의 작은 배지로 표기한다. 우선 "거래처별 매출" 항목에 "영업" 배지를 붙여 확인한다. 일반 팀원 계정(자기 팀 메뉴만 보임)에는 배지를 표시하지 않는다 — 이미 소속팀이 자명하므로.

## 영향 범위
- `components/layout/nav-items.ts`: `NavItem` 타입에 소속팀 메타데이터 추가
- `components/layout/AppShell.tsx`: 관리자 뷰일 때 배지 렌더링
- `app/(app)/layout.tsx`: AppShell에 관리자 여부 전달
