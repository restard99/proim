# TASK-001: 관리자 사이드바 업무 메뉴 소속팀 배지 — 아티팩트

## 상태: 완료

## 수정 내용
관리자 계정에서만 사이드바 업무 메뉴 항목 오른쪽에 소속팀을 나타내는 어두운 톤(검정 반투명 배경 + 연한 회색 글자)의 작은 배지를 표시하도록 했다. 일반 팀원 계정에서는 배지가 뜨지 않는다.

## 수정된 파일
- `components/layout/nav-items.ts`: `NavItem`에 `team?: string` 추가, 각 업무 메뉴에 소속팀 값 지정 (거래처별 매출/수금현황→영업, 재고현황→영업채산, 생산의뢰서→영업채산·생산, 생산일지→생산, 생산량/부자재재고현황→염전관리)
- `components/layout/AppShell.tsx`: `NavLinkRow`에 `showTeamBadge` prop과 배지 렌더링 추가. `isAdmin`은 `adminNavItems.length > 0`으로 판별해 별도 prop 추가 없이 처리 (view-as로 다른 팀원 화면을 볼 때는 실제 세션이 그 팀원 것이라 adminNavItems가 비고, 배지도 자동으로 숨겨짐)

## 완료 기준 확인
- [x] 관리자 계정으로 로그인 시 "거래처별 매출" 항목 오른쪽에 "영업" 배지가 어두운 톤으로 표시됨
- [x] 다른 업무 메뉴 항목에도 각자 소속팀 배지가 표시됨
- [x] 일반 팀원 계정(비관리자)에는 배지가 표시되지 않음
- [x] `npx tsc --noEmit` 통과

## 이슈 및 결정사항
스펙에는 `app/(app)/layout.tsx`에서 `isAdmin`을 새로 내려주는 것으로 적었으나, `adminNavItems`가 이미 관리자 여부를 함축하고 있어 AppShell 내부에서 파생시키는 쪽으로 단순화했다. 동작은 동일하다.
