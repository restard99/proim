# 매출/생산 목표 — 실제 주간업무보고 워크북 직접 반영 기획서

## 개요
"매출 목표 관리" 업로드를 수기 템플릿 방식에서 실제 "주간_월간_업무보고" 워크북을 그대로 업로드하는 방식으로 바꾼다. 이 워크북 안의 정해진 위치에서 목표(계획)값을 자동으로 뽑아 반영한다. 더불어 **주간업무보고 화면의 섬들채 페이지(6번)**를 지금의 "채널별 매출" 표에서 "업장별 매출목표/실적" 표로 교체한다 (손익자료 화면은 건드리지 않음).

## 사용자
관리자(업로드), 임원실(주간업무보고에서 목표 대비 실적 확인)

## 해결하는 문제
- 관리자가 이미 워크북에 있는 수치를 별도 템플릿에 다시 옮겨 적어야 함(이중 작업, 오타 위험)
- 섬들채는 지금 법인 전체 목표 1건으로만 관리돼 업장별(소금가게/쇼핑몰/…) 목표 대비 실적을 못 봄. 업장별 실적은 Y-ERP 실시간 집계로는 구분이 안 되고(거래처명 체계가 안 맞음), 이 워크북에만 정확한 수치가 있음이 확인됨

## 기대 효과
- 워크북 업로드 한 번으로 태평소금/태평염전/박물관 법인 매출목표(주간+월간)와 섬들채 업장별(+전체) 매출목표·실적(주간+월간), 생산목표(월간)가 모두 반영됨
- 주간업무보고 6번 페이지가 PPT 원본과 동일하게 "구분/주간(계획·실적·달성률)/월간(계획·실적·달성률)"으로 표시됨 (전년동월 비교는 이 워크북에 작년 9월 데이터가 없어 제외)

## 범위
### 포함
- 새 업로드(워크북 그대로) → 태평소금/태평염전/박물관 매출목표(주간+월간) → 기존 `executive_targets`에 반영
- 새 업로드 → 태평소금 생산목표(천일염/가공염), 태평염전 생산목표(월간만) → 기존 `executive_targets`에 반영 (주간은 이번 범위 제외)
- 새 업로드 → 섬들채 전체+업장별(6개)+박물관 목표·실적(주간+월간) → 새 테이블에 저장
- "매출 목표 관리" 화면의 업로드 UI를 이 새 업로드 하나로 교체 (기존 수기 템플릿 UploadSection 제거, 템플릿 파일 자체는 남겨둠)
- 주간업무보고 6번 페이지(섬들채)를 "채널별 매출" 표 → "업장별 매출목표/실적" 표로 교체

### 제외
- 손익자료 화면 변경 없음 (`executive_pl_business_unit` 등 기존 부문별 손익 기능은 그대로 둠)
- 전년동월 비교 (데이터 없음 — 추후 소스가 생기면 별도 진행)
- 생산목표 주간 값 (이번엔 월간만)
- 섬들채 외 법인의 업장별 목표
