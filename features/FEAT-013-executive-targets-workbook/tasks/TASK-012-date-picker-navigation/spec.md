# TASK-012: 주간업무보고 월 단위 조회 → 기간(월 범위) 실적 합산 조회

## 목적
주간업무보고 조회 방식을 지난주/다음주 버튼 기본으로 유지하면서, 여러 달에 걸친 실적을 한 번에 합산해서 볼 수 있도록 보완한다. "3~6월까지 조회"처럼 임의의 월 범위를 지정하면 계획(목표) 없이 실적만 전체 6개 페이지에 걸쳐 합산해 보여준다.

## 작업 범위
- 수정할 파일: `app/actions/executive-report.ts`, `components/executive/WeeklyReportView.tsx`

## 완료 기준
- [x] "← 지난 주" / "다음 주 →" 버튼은 기존 그대로 동작(기본 조회 방식)
- [x] "📅 기간 조회" 버튼 클릭 → 달력 팝오버에서 첫 번째 클릭한 달이 시작월, 두 번째 클릭한 달이 종료월(그 달 마지막 날까지)이 되어 바로 조회
- [x] 기간 조회 시 1~6페이지 전체에 계획 없이 실적만 합산해서 표시
- [x] "주간 보고로 돌아가기" 버튼으로 평상시 주간 보기로 복귀
- [x] `npx tsc --noEmit`, `npx eslint`, `npm run build` 통과

## 변경 이력
1. 최초에는 일(day) 단위 `<input type="date">`로 구현.
2. 사용자가 "월단위가 좋겠다" + "3~6월처럼 여러 달을 조회할 방법이 없다"고 지적해 월 선택 + 이전/다음 달 버튼으로 교체.
3. 사용자가 "이전달/다음달 없애고 달력을 클릭해서 시작달/종료달(그 달 마지막날까지)을 선택하는 방식"을 요청했고, 이어서 "계획은 안 뜨겠지만 실적만 합산 조회 가능하지 않냐"고 확인 → 범위를 1~6페이지 전체로 정해(사용자 선택) 계획 없이 실적만 합산하는 "기간 조회" 모드로 최종 구현.
