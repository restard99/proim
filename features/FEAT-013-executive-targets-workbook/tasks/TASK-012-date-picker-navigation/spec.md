# TASK-012: 주간업무보고 월 단위 조회

## 목적
주간업무보고 조회 방식을 지난주/다음주 버튼 기본에서, 월 단위로도 원하는 시점을 바로 조회할 수 있도록 보완한다. 특히 "3~6월까지 조회"처럼 여러 달을 연속으로 훑어보는 경우를 지원한다.

## 작업 범위
- 수정할 파일: `components/executive/WeeklyReportView.tsx`

## 완료 기준
- [x] "← 지난 주" / "다음 주 →" 버튼은 기존 그대로 동작(기본 조회 방식)
- [x] 월 선택(`<input type="month">`)으로 특정 월의 첫째 주로 바로 이동
- [x] "◀ 이전 달" / "다음 달 ▶" 버튼으로 월 단위 연속 이동 (예: 3→4→5→6월)
- [x] 월 선택 UI는 현재 조회 중인 주가 속한 월을 표시
- [x] `npx tsc --noEmit`, `npx eslint` 통과

## 변경 이력
- 최초에는 일(day) 단위 `<input type="date">`로 구현했으나, 사용자가 "월단위가 좋겠다"고 요청 + "3~6월처럼 여러 달을 조회할 방법이 없다"는 문제를 제기해 월 선택 + 이전/다음 달 버튼 조합으로 교체.
