# TASK-012: 주간업무보고 월 단위 조회 — 아티팩트

## 상태: 완료

## 구현 내용
헤더의 "← 지난 주" / "다음 주 →" 버튼(기본 조회 방식)은 그대로 두고, 그 옆에 월 단위 조회 컨트롤을 추가했다:
- "◀ 이전 달" / "다음 달 ▶" 버튼: 현재 보고 있는 주가 속한 월 기준으로 한 달씩 이동, 이동한 월의 1일이 속한 주(월요일)로 보고서를 불러온다. 여러 달을 연속으로 훑어보고 싶을 때(예: 3~6월) 버튼을 반복 클릭하면 된다.
- 월 선택(`<input type="month">"`): 특정 월을 바로 지정하면 그 달 1일이 속한 주로 즉시 이동한다.

두 컨트롤 모두 값 변경 시 `mondayOf()`로 대상 월 1일이 속한 주의 월요일을 계산해 `loadWeek()`를 재사용한다. 월 선택 UI에 표시되는 값(`currentMonth`)은 `weekStartDate.slice(0,7)`로 계산하는데, 서버의 `monthRange(weekStartDate)`도 동일한 weekStartDate에서 월을 파생시키므로 항상 실제 조회 중인 월과 일치한다.

최초에는 일(day) 단위 `<input type="date">`로 구현했으나, 사용자가 "월단위가 좋겠다" + "3~6월처럼 여러 달을 조회할 방법이 없다"고 지적해 월 선택 + 이전/다음 달 버튼 조합으로 교체했다.
