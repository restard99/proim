# TASK-015: 태평염전 매출 페이지에 판매처별 실적(채널별) 표 추가 — 아티팩트

## 상태: 배포 완료 (마이그레이션 적용 및 실제 업로드로 검증 완료)

## 구현 내용
"2. 태평염전 매출" 화면에 "■ 판매처별 실적" 표를 새로 추가했다: "■ 주간 매출 실적" 요약과 기존 판매처명/금액 표(Y-ERP 거래처 기준, `CustomerTable`) 사이에 위치하며, 도매/관내,기타/태평소금/서비스사업부/합계 채널별로 주간·월간 수량/금액/단가를 보여준다.

데이터는 "매출-태평염전2" 탭에서 가져오는데, 이 시트를 실제로 열어보고서야 정확한 구조를 파악했다:
- 이 탭의 531행 이전은 옛날/다른 용도로 쓰인 동일한 모양의 표가 반복돼 있어 헷갈리기 쉽고, **531행 이후만 유효**하다(사용자 확인).
- 531행 이후는 "n월"(01월~09월처럼 그 달까지 실제로 보고서를 만든 달만) 표가 이어지다가, 맨 마지막에 "MM.DD-MM.DD" 형식(예: "08.31-09.06")의 표가 하나 더 있다.
- 실측 결과 마지막 날짜범위 표가 PPT의 "주간" 열, 마지막 "n월" 표가 "월간" 열에 각각 대응한다.
- 단가는 특이한 규칙이 있다: 표의 "합계" 열 자체의 단가(금액÷수량으로 정확히 계산된 값)와, 실제 활성화된 개별 상품유형 열에 별도로 적힌 단가가 다를 수 있는데 — 원본 워크북과 PPT 둘 다 개별 상품유형 열의 단가를 그대로 쓴다. 그래서 개별 열에 단가가 있으면 그걸 우선하고, 없을 때만 합계 열의 단가로 대체하도록 구현했다.

## 시행착오
데이터 위치를 찾는 데 여러 차례 사용자 확인이 필요했다:
1. 처음엔 "매출-태평염전1"의 뒤이은 열/블록을 잘못 짚어 실제 숫자와 안 맞았다.
2. 사용자가 "매출-태평염전2"를 알려줬으나, 이 시트의 3~530행(반복되는 "1월~12월" 블록 3세트)을 잘못 짚어 또 안 맞았다(매출목표 대비 3.6배 큰 비현실적인 값이 나옴).
3. 사용자가 "행은 531부터"라고 정정해준 뒤에야 정확한 위치(531행 이후, 채널별 5개 행 × [수량/금액/단가] × 상품유형 열)를 찾았고, 실측 결과 PPT의 모든 수치와 정확히 일치함을 확인했다.
