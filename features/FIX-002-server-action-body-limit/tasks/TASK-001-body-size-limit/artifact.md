# TASK-001: 서버 액션 바디 크기 제한 상향 — 아티팩트

## 상태: 완료

## 수정 내용
`next.config.ts`에 `experimental.serverActions.bodySizeLimit: "15mb"`를 추가해 업로드 액션들의 자체 검증 한도(15MB)와 프레임워크 제한을 일치시켰다.

## 수정된 파일
- `next.config.ts`

## 완료 기준 확인
- [x] `npx tsc --noEmit` 통과
- [ ] 1MB 넘는 실제 엑셀 파일 업로드 성공 확인 — 배포 후 실사용자 테스트 필요

## 이슈 및 결정사항
이 제한은 서버 액션 전역 설정이라, 생산의뢰서/생산일지 업로드 등 다른 기존 업로드 기능들도 그동안 1MB 넘는 파일에서 같은 문제를 겪었을 가능성이 높다 — 이번 수정으로 함께 해결된다.
