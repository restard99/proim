# 출금조회 엑셀 내보내기 기획서

## 개요
출금조회(FEAT-009) 화면에서 현재 조회 중인 법인·기간의 매입처별 요약과 전체 매입처의 상세 거래내역을 엑셀 파일로 내보낼 수 있게 한다.

## 사용자
관리자(admin)

## 해결하는 문제
출금조회 화면은 매입처를 하나씩 클릭해야 상세 거래내역(일자별 차변/대변)을 볼 수 있어, 전체 매입처의 상세 내역을 한 번에 보거나 다른 곳에 공유·보관하기 어렵다.

## 기대 효과
- 화면에서 보던 것과 동일한 조건(법인·기간·검색어)으로 엑셀 파일을 바로 받을 수 있다
- 엑셀 한 시트 안에 매입처별 요약표와, 그 아래 전체 매입처의 일자별 상세 거래내역이 함께 들어있어 따로 클릭해볼 필요 없이 전체를 확인할 수 있다

## 범위
### 포함
- 화면에 "엑셀 다운로드" 버튼 추가
- 내보내는 범위: 현재 선택된 법인(탭) + 현재 조회기간 + 현재 검색어 조건 그대로 (예: 섬들채 탭에서 누르면 섬들채 데이터만)
- 엑셀 구성(한 시트):
  1. 상단: 매입처별 요약표 (매입처 / 기초잔액 / 매입발생 / 지급액 / 기말잔액) — 화면의 목록과 동일
  2. 하단: 요약표에 나온 전체 매입처의 상세 거래내역을 매입처별로 이어서 나열 (일자 / 구분(매입발생·지급) / 적요·상대계정 / 금액 / 잔액), 매입처 구분을 알아볼 수 있도록 매입처명을 표시
- 파일명에 법인명과 조회기간 포함

### 제외
- 3개 법인을 한 파일에 합쳐서 내보내는 기능 (법인별로 각각 받는 방식 유지)
- 엑셀 서식 꾸미기(색상/테두리 등 디자인) 고도화 — 가독성 있는 기본 표 정도로 충분
- 엑셀 업로드/가져오기 기능
