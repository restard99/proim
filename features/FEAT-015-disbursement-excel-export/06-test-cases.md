# 출금조회 엑셀 내보내기 테스트 케이스

## 테스트 전 준비사항
- 관리자 계정으로 로그인
- 좌측 메뉴에서 "출금조회" 진입
- 로컬 개발 서버 실행 중 (`npm run dev`)

## 정상 케이스

### TC-001: 기본 다운로드
**조건:** 데이터가 있는 법인·기간으로 조회된 상태
**단계:**
1. 법인 탭(태평소금/태평염전/섬들채) 중 하나 선택
2. 조회기간을 데이터가 있는 범위로 지정
3. "엑셀 다운로드" 버튼 클릭
**기대 결과:** 잠깐 "생성 중…" 상태가 보인 뒤, `{법인명}_출금조회_{시작일}_{종료일}.xlsx` 파일이 다운로드된다. 열어보면 상단에 화면과 동일한 매입처별 요약표, 하단에 전체 매입처의 일자별 상세내역(매입처명 구분행 포함)이 들어있다.
**결과:** [ ] 통과 / [ ] 실패

### TC-002: 검색어 적용 상태에서 다운로드
**단계:**
1. 매입처 검색창에 특정 거래처명(일부) 입력
2. 목록이 필터링된 상태에서 "엑셀 다운로드" 클릭
**기대 결과:** 엑셀에도 화면에 보이는 필터링된 매입처만 포함된다.
**결과:** [ ] 통과 / [ ] 실패

### TC-003: 법인 선택에 따른 범위 확인
**단계:**
1. "섬들채" 탭에서 다운로드
2. "태평소금" 탭으로 바꿔서 다시 다운로드
**기대 결과:** 각 파일에는 선택했던 해당 법인의 데이터만 들어있고, 다른 법인 데이터가 섞이지 않는다.
**결과:** [ ] 통과 / [ ] 실패

**단계:**
1. 매입처가 많이 나오는 넓은 기간(예: 연초~오늘)으로 조회 후 다운로드
**기대 결과:** 매입처 수와 무관하게 몇 초 내에 생성이 끝난다 (일괄 조회 방식이라 매입처 수에 비례해 느려지지 않아야 함).
