### TC-002: 개인별 메뉴 추가 허용
**조건:** "게시판 권한" 탭, 테스트 대상 계정 선택
**단계:**
1. 팀 규칙으로 안 보이는 메뉴(예: 거래처별 매출) 체크박스를 켠다

3. 해당 계정으로 로그인(또는 새로고침)
**기대 결과:** 왼쪽 메뉴에 해당 항목이 나타나고, 클릭해서 실제로 접근된다(리다이렉트 안 됨)
