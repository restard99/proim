# 개인별 게시판(메뉴) 권한 부여 기획서

## 개요
관리자가 "가입 승인 관리" 화면의 새 탭("게시판 권한")에서, 특정 사람에게 그 사람의 소속팀 규칙으로는 원래 안 보이는 업무 메뉴를 개별적으로 추가로 열어줄 수 있게 한다.

## 사용자
관리자(권한 부여), 권한을 받은 개인(추가로 열린 메뉴 이용)

## 해결하는 문제
현재 왼쪽 메뉴 접근 권한은 `profiles.team`/`role` 조합으로만 정해진다(`components/layout/nav-items.ts`의 `canView*` 함수들). 그래서 "이 사람만 예외적으로 다른 팀 메뉴도 보게 해주고 싶다"는 요청이 오면 코드를 고쳐야 한다. 개인별로 예외를 즉시 부여/회수할 수 있는 관리 화면이 없다.

## 기대 효과
- 관리자가 코드 수정 없이 특정 인원에게 필요한 메뉴를 추가로 열어줄 수 있음
- 기존 팀 기반 권한 체계는 그대로 유지되어 안전함(개인별 설정은 "추가 허용"만 가능, 팀 규칙으로 원래 보이는 메뉴를 뺏을 수는 없음)

## 범위
### 포함
- "가입 승인 관리" 화면을 탭 구조로 재구성: **가입 승인** / **전체 사용자** / **게시판 권한** 3개 탭 (기존 두 섹션은 각각 탭으로 이동, 새 탭 추가)
- "게시판 권한" 탭: 사용자 선택 → 팀 구분이 있는 업무 메뉴 목록에 체크박스로 추가 허용 여부 표시/변경
  - 대상 메뉴: 거래처별 매출·수금현황(영업), 재고현황(영업채산), 출금조회(관리자 전용이라 이미 항상 보임 — 대상에서 제외), 생산의뢰서, 생산일지, 원재료·반제품 현황, 생산량·부자재재고현황(염전관리), 주간업무보고·손익자료(임원실)
  - 관리자 전용 메뉴(가입 승인 관리, 시스템검토 게시판, 매출 목표 관리)와 항상 보이는 기본 메뉴(홈, 일정관리, 업무일지)는 대상에서 제외
- 권한 판정 로직: "팀 규칙으로 원래 보임" **OR** "개인별로 추가 허용됨" → 보임 (추가 허용만, 팀 규칙보다 우선해서 숨기는 기능은 없음)
- 관리자 본인은 이미 모든 메뉴가 보이므로 대상에서 제외

### 제외
- 개인별로 팀 규칙보다 우선해서 메뉴를 "숨기는" 기능 (이번 범위 아님 — 필요해지면 별도 기능으로)
- 관리자 전용 메뉴에 대한 개인별 권한 부여
- 메뉴 안의 세부 동작 권한(예: 생산의뢰서 업로드는 팀장만) 개인별 조정 — 이번 범위는 "메뉴가 보이는지"만 다룸
