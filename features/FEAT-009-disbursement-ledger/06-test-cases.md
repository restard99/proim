# 출금조회 테스트 케이스

## 테스트 전 준비사항
- 관리자(admin) 계정과, 관리자가 아닌 일반 계정(예: 영업채산팀 팀원) 두 종류로 로그인 테스트 필요
- 개발 서버 실행 중이어야 함 (`npm run dev`)

## 정상 케이스

### TC-001: 관리자 사이드바에 출금조회 탭 표시
**조건:** 관리자 계정으로 로그인
**단계:**
1. 좌측 사이드바 확인
**기대 결과:** "재고현황" 바로 아래에 "출금조회" 탭이 "관리자" 배지와 함께 표시된다

### TC-002: 매입처 목록 조회
**조건:** 관리자 계정으로 로그인 후 "출금조회" 클릭
**단계:**
1. 기본 조회기간(올해 1월 1일 ~ 오늘)으로 화면 진입
**기대 결과:** 매입처별 기초잔액/매입발생/지급액/기말잔액이 표시되고, 상단 요약 카드(기간 지급액/미지급 잔액/미지급 매입처)가 목록 합계와 일치한다

### TC-003: 원장 상세 조회
**조건:** TC-002 화면에서 잔액이 있는 매입처 행 클릭
**단계:**
1. 매입처 행을 클릭해 원장을 펼친다
**기대 결과:** 일자순으로 매입발생(파란색)/지급(적색) 내역과 적요, 누적잔액이 표시되고, 마지막 줄의 누적잔액이 목록의 기말잔액과 일치한다

### TC-004a: 법인 전환
**조건:** 관리자 계정으로 "출금조회" 화면 진입
**단계:**
1. 상단 법인 탭에서 "태평염전", "섬들채"를 차례로 클릭
**기대 결과:** 법인을 바꿀 때마다 매입처 목록과 합계가 해당 법인 데이터로 다시 조회된다 (태평소금과 다른 매입처들이 표시됨)

### TC-004: 기간/거래처 검색 필터
**조건:** TC-002 화면
**단계:**
1. 조회기간을 좁혀본다
2. 매입처 검색창에 특정 거래처명 일부를 입력한다
**기대 결과:** 목록이 조건에 맞게 다시 조회된다

## 예외 케이스

### TC-005: 관리자가 아닌 계정은 메뉴/화면 접근 불가
**조건:** 관리자가 아닌 계정으로 로그인
**단계:**
1. 좌측 사이드바 확인
2. 주소창에 `/disbursements`를 직접 입력해 접속 시도
**기대 결과:** 사이드바에 "출금조회" 탭이 보이지 않고, 직접 접속 시 홈(`/`)으로 리다이렉트된다

### TC-006: 데이터 없는 기간 조회
**조건:** 관리자 계정, 거래가 없는 과거 기간(예: 2020년) 선택
**단계:**
1. 조회기간을 데이터가 없는 기간으로 설정
**기대 결과:** "해당 기간 출금 데이터가 없습니다" 문구가 표시된다
