# 출금조회 기획서

## 개요
Y-ERP의 외상매입금(0251) 계정 일반전표 내역을 매입처(거래처)별로 조회하는 화면. 부자재 등 물품 매입 대금이 언제, 얼마나 지급(출금)됐는지 확인할 수 있다.

## 사용자
관리자(admin)

## 해결하는 문제
Y-ERP에는 매입지급 전용 모듈이 있지만 실제로는 사용되지 않고, 회계 담당자가 일반전표에 외상매입금 계정을 직접 분개하는 방식으로만 처리된다. 이 원장 데이터를 조회할 수 있는 화면이 사내 시스템에 없어, 매입처별 대금 지급 현황을 파악하기 어렵다.

## 기대 효과
- 매입처별 외상매입금 기초잔액/기간 중 발생(차변)·지급(대변)/잔액을 한눈에 확인
- 특정 매입처를 선택하면 일자별 차변·대변 상세 내역(원장)을 조회

## 범위
### 포함
- 좌측 탭에 "출금조회" 메뉴 추가 (재고현황 하단, 관리자 전용)
- 법인 선택: 태평소금(0460) / 태평염전(0400) / 섬들채(0360) 3개 법인을 탭으로 전환하며 조회
  - (수정) Y-ERP가 한 DB에서 여러 법인을 CORP_CODE로 나눠 관리하는 구조임을 확인, 세 법인 모두 0251/0253 계정에 실데이터가 있어 법인 선택 탭을 추가함
- 매입처별 목록 화면: 기초잔액 / 기간 중 발생(차변) / 기간 중 지급(대변) / 잔액
- 기간 선택(시작일~종료일), 거래처명 검색
- 매입처 클릭 시 상세 원장 화면: 일자별 차변/대변 내역, 적요, 상대계정, 누적잔액
- 대상 계정: 외상매입금(0251) + 미지급금(0253)
  - (수정) 최초에는 0251만 대상으로 했으나, 실사용 테스트 중 부자재 매입처(수정실업/원지/제일산업 등)가 목록에서 전부 빠지는 문제 발견 → 조사 결과 Y-ERP는 원재료(소금) 매입은 0251, 부재료(부자재)는 0253으로 계정을 나눠 쓰고 있어 0253을 추가함

### 제외
- 부자재/품목 단위 세분화 (원장이 거래처 단위로만 기록되어 있어 불가능 — 기존 조사 결과)
- 데이터 수정/입력 기능 (Y-ERP는 읽기 전용 연동)
