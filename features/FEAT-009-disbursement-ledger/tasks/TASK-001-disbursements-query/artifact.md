## 추가 수정 (6단계 테스트 피드백 반영)
0251만 조회했을 때 부자재 매입처(수정실업/원지/제일산업)가 목록에서 누락되는 문제가 발견됐다. 조사 결과 부재료(부자재) 매입은 0253(미지급금)으로 기표되고 있어, `AC_PURC_SALE_T`와 대조 검증(673건 전부 대변) 후 `AP_ACCOUNT_CODES = ["0251", "0253"]`로 확장하고 두 계정을 `IN` 절로 함께 조회하도록 수정했다. 실데이터 재검증: 150개 매입처로 확장, 제일산업 원장(매입발생/지급 15건)의 최종 누적잔액이 목록 잔액(-12,835,988)과 정확히 일치.
자세한 내용은 `01-spec.md`/`03-decisions.md`의 "계정 범위 수정" 참고.

## 추가 수정 2 (법인 확장)
