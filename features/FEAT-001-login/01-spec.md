# 로그인 기획서

## 개요
전사 일일업무보고 시스템(팀원 작성 → 팀장 확인 → 대표 보고 → 전략기획실 주간보고 제출)의 진입 관문으로, 사용자의 소속팀·직급을 식별해 역할별 화면과 권한으로 안내하는 회원가입·로그인 기능이다.

## 사용자
전사 9개 팀 소속 팀원·팀장, 대표, 시스템 관리자.

| 팀 | 팀장 | 팀원 |
|---|---|---|
| 생산팀 | 1 | 2 |
| 회계팀 | 1 | 2 |
| 환경안전팀 | 1 | - |
| 영업채산팀 | 1 | 2 |
| 섬들채 | 1 | F&B웰니스 5, 소매서비스 4, 전시교육 3 |
| 증도지원팀 | 1 | 3 |
| 전략기획실 | 1 | 구매채산 1, 마케팅 1 |
| 염전관리팀 | 1 | 3 |

- 위 인원 외 **대표 1명**이 별도 역할로 로그인한다.
- **시스템 관리자 계정**을 별도로 두어 가입 승인을 전담한다 (조직표상 팀 소속과 무관한 별도 계정).
- 역할 구분: **팀원 / 팀장 / 대표** (관리자는 승인 전용 별도 역할)

## 해결하는 문제
현재는 전사 일일업무보고 흐름(팀원 작성 → 팀장 확인 → 대표 보고 → 전략기획실 주간보고)을 담을 시스템 진입 체계가 없다. 로그인 시 사용자의 소속팀·직급이 식별되지 않으면 이후 단계(팀원 작성 화면, 팀장 확인 화면, 대표 확인·피드백 화면)에 맞는 권한과 화면을 제공할 수 없다.

## 기대 효과
- 이름·소속팀·직급·비밀번호로 회원가입하면 관리자 승인 후 사용 가능해진다.
- 승인된 사용자는 이름·소속팀·비밀번호로 로그인하면 본인의 팀·역할에 맞는 화면으로 이동한다. (소속팀을 함께 입력받아 동명이인이 다른 팀 소속이면 별도 계정으로 가입·로그인할 수 있다)
- 관리자는 대기 중인 가입 요청을 확인하고 승인/반려할 수 있다.

## 범위

### 포함
- 회원가입: 이름(아이디), 소속팀, 직급(팀원/팀장/대표), 비밀번호 입력
- 가입 후 "승인 대기" 상태 부여, 관리자 승인 전 로그인 불가
- 관리자 전용 계정: 대기 중인 가입 요청 목록 확인, 승인/반려 처리
- 로그인: 이름 + 소속팀 + 비밀번호 (이름+소속팀 조합이 로그인 식별자)
- 로그인 성공 시 역할(팀원/팀장/대표)에 따른 진입 처리 기반 마련

### 제외
- 소셜 로그인(카카오 등)
- 비밀번호 찾기/재설정 (이번 범위에서 제외, 필요 시 관리자가 수동 처리)
- 이메일/SMS 인증
- 같은 팀 내 동명이인 처리 (이름+소속팀으로도 겹치는 경우는 관리자 문의로 해결, 자동화하지 않음)
