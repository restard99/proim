# FIX-007 테스트 케이스

## TC-001: 소속팀을 먼저 고른 뒤 이름을 입력해도 선택값 유지
**조건:** `/login`, 완전히 로그아웃된 상태
**단계:**
1. 소속팀 드롭다운에서 본인 팀이 아닌 다른 팀을 먼저 선택한다
2. 그 다음 이름 입력창에 본인 이름을 입력하고 포커스를 뺀다(Tab 등)
**기대 결과:** 소속팀 값이 자동으로 바뀌지 않고, 1번에서 고른 팀이 그대로 유지된다
**결과:** [ ] 통과 / [ ] 실패

## TC-002: 다른 팀 + 본인 이름 + 본인 비밀번호로 로그인 시도 시 차단
**조건:** `/login`
**단계:**
1. 본인 이름 입력
2. 소속팀을 본인 실제 팀이 아닌 다른 팀으로 선택 (자동완성이 채워준 값을 수동으로 바꿈)
3. 본인 비밀번호 입력 후 로그인
**기대 결과:** "이름, 소속팀 또는 비밀번호가 올바르지 않습니다" 오류가 뜨고 로그인되지 않는다
**결과:** [ ] 통과 / [ ] 실패

## TC-003: 기존 정상 로그인 회귀 확인
**조건:** `/login`
**단계:**
1. 이름만 입력하고 blur (소속팀을 직접 건드리지 않음)
2. 자동으로 채워진 본인 소속팀 확인
3. 비밀번호 입력 후 로그인
**기대 결과:** 자동완성이 정상 동작하고, 정상적으로 로그인된다
**결과:** [ ] 통과 / [ ] 실패

## TC-004: 이름을 다시 수정하면 자동완성 재동작
**조건:** `/login`
**단계:**
1. 이름 A 입력 후 blur (팀 자동완성됨)
2. 이름을 B로 다시 수정하고 blur
**기대 결과:** B에 해당하는 소속팀으로 다시 자동완성된다 (A의 팀이 남아있지 않음)
**결과:** [ ] 통과 / [ ] 실패
