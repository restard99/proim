# TASK-001: 소속팀 자동완성 레이스 컨디션 제거

## 목적
이름 입력 시 자동으로 소속팀을 채워주는 기능이, 사용자가 이미 수동으로 소속팀을 선택한 뒤에는 그 값을 덮어쓰지 않도록 한다.

## 작업 범위
- 수정할 파일: `components/auth/LoginForm.tsx`
  - 소속팀 `<select>`가 사용자에 의해 직접 변경되었는지 추적하는 상태(예: `teamTouched`)를 추가한다.
  - `onChange`에서 `teamTouched`를 true로 설정한다.
  - `handleNameBlur`의 자동완성 덮어쓰기는 `teamTouched`가 false일 때만 수행한다.
  - 이름을 다시 수정하면(다른 사람 이름으로 바꾸는 경우) 자동완성이 다시 동작해야 하므로, 이름 입력값이 바뀌면 `teamTouched`를 리셋할지 여부도 검토한다 → 이름이 바뀌면 소속팀도 사용자가 다시 확인해야 하므로 이름 `onChange` 시 `teamTouched`를 false로 리셋한다.

## 완료 기준
- [ ] 소속팀을 수동으로 먼저 선택한 뒤 이름을 입력/blur해도 수동 선택값이 유지된다.
- [ ] 이름만 입력하고 소속팀을 건드리지 않으면 기존처럼 자동완성이 정상 동작한다.
- [ ] 이름을 다시 바꾸면 자동완성이 다시 시도된다.
- [ ] `npx tsc --noEmit` 통과
