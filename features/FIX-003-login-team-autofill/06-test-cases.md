# FIX-003 테스트 케이스

## TC-001: 소속팀 자동 매칭
**조건:** 소속팀이 하나뿐인 계정의 이름을 알고 있음
**단계:**
1. `/login`에서 이름 입력 후 다른 칸(소속팀 또는 비밀번호) 클릭
**기대 결과:** 소속팀 드롭다운이 자동으로 그 계정의 소속팀으로 선택된다
**결과:** [ ] 통과 / [ ] 실패

## TC-002: 동명이인 자동 매칭 안 됨
**조건:** 같은 이름으로 다른 팀에 가입된 계정이 2개 이상 있음 (없으면 테스트용으로 만들어서 확인)
**단계:**
1. 그 이름을 입력 후 다른 칸 클릭
**기대 결과:** 소속팀이 자동으로 채워지지 않고 "선택하세요" 상태 그대로 유지된다
**결과:** [ ] 통과 / [ ] 실패
