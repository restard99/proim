# FIX-003: 로그인 화면에서 이름 입력 시 소속팀 자동 매칭

## 문제 상황
로그인 화면에서 이름과 소속팀을 둘 다 직접 골라야 해서 매번 번거롭다. 실제로는 이름만 입력해도 대부분 어느 팀 소속인지 특정 가능한 경우가 많다.

## 현재 동작
이름(텍스트 입력) + 소속팀(직접 선택하는 드롭다운)을 둘 다 채워야 로그인 가능.

## 기대 동작
이름 입력창에서 포커스를 벗어나면(blur), 그 이름으로 가입된 계정의 소속팀을 자동 조회한다.
- 일치하는 팀이 1개면 소속팀 드롭다운에 자동으로 채워준다 (사용자가 다시 바꿀 수도 있음)
- 일치하는 팀이 여러 개(동명이인, 다른 팀)면 자동 채우지 않고 그대로 선택하게 둔다
- 일치하는 계정이 없으면 아무 동작 안 함(기존과 동일하게 직접 선택)

## 영향 범위
- 새 RPC: 이름으로 소속팀 목록을 조회하는 함수 (계정 존재 여부 노출을 최소화하기 위해 소속팀 목록만 반환, 승인 상태 등은 반환 안 함)
- `app/actions/auth.ts`: 위 RPC를 호출하는 서버 액션 추가
- `components/auth/LoginForm.tsx`: 이름 입력 blur 시 자동 매칭 로직 추가
