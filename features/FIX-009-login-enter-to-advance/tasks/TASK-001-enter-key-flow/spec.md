# TASK-001: 이름 입력창 엔터키 처리 및 안내 문구 변경

## 목적
이름 입력 후 엔터 키로 소속팀 자동완성 + 비밀번호 필드 포커스 이동까지 한 번에 처리한다.

## 작업 범위
- 수정할 파일: `components/auth/LoginForm.tsx`
  - 기존 blur 로직을 `runTeamLookup(name)` 공용 함수로 추출
  - 이름 입력창에 `onKeyDown` 추가: Enter 시 `preventDefault`, `runTeamLookup` 실행 후 비밀번호 입력창에 포커스
  - blur와 keydown(Enter)이 동시에 중복 호출되지 않도록 가드 처리
  - 비밀번호 입력창에 `ref` 추가
  - 안내 문구를 "동명이인이 있을 수 있어 소속팀과 함께 계정을 구분합니다. 입력 후 엔터를 치세요."로 변경

## 완료 기준
- [ ] 이름 입력 후 Tab/blur로 필드를 벗어나면 기존과 동일하게 동작 (회귀 없음)
- [ ] 이름 입력 후 엔터 시 폼이 제출되지 않고, 소속팀이 자동완성되며, 포커스가 비밀번호로 이동
- [ ] 이메일(관리자) 입력 후 엔터 시 소속팀 조회 없이 바로 비밀번호로 포커스 이동
- [ ] blur와 keydown 중복 호출로 인한 이중 조회 없음
- [ ] `npx tsc --noEmit` 통과
