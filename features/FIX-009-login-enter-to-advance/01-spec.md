# FIX-009: 로그인 화면 - 이름 입력 후 엔터로 다음 단계 진행

## 문제 상황
로그인 화면에서 이름을 입력한 뒤 소속팀 자동완성을 받으려면 Tab이나 마우스 클릭으로 필드를 벗어나야 했고, 안내 문구도 "관리자 계정은 이메일을 입력하세요"로 되어 있어 엔터 사용법을 안내하지 않았음.

## 현재 동작
- 이름 입력창의 안내 문구: "동명이인이 있을 수 있어 소속팀과 함께 계정을 구분합니다. 관리자 계정은 이메일을 입력하세요."
- 이름 입력 후 blur(포커스 이탈) 시에만 소속팀 자동완성이 동작함. 엔터 키는 별도 처리가 없어 폼 제출을 시도함(비밀번호가 비어 있어 검증 오류 발생).

## 기대 동작
- 안내 문구를 "동명이인이 있을 수 있어 소속팀과 함께 계정을 구분합니다. 입력 후 엔터를 치세요."로 변경
- 이름 입력 후 엔터를 치면:
  1. 폼이 바로 제출되지 않는다
  2. 기존 blur와 동일하게 소속팀 자동완성이 동작한다 (동명이인 없을 시 자동 채움, 이메일 입력 시 스킵)
  3. 포커스가 비밀번호 입력창으로 바로 이동한다
