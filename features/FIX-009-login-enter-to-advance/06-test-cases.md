# FIX-009 테스트 케이스

## TC-001: 이름 입력 후 엔터 → 소속팀 자동완성 + 비밀번호로 포커스 이동
**조건:** `/login`
**단계:**
1. 본인 이름 입력 후 엔터를 친다
**기대 결과:** 폼이 제출되지 않고, 소속팀이 자동으로 채워지며, 커서가 비밀번호 입력창으로 이동한다
**결과:** [x] 통과 / [ ] 실패

## TC-002: 관리자(이메일) 입력 후 엔터 → 바로 비밀번호로 이동
**조건:** `/login`
**단계:**
1. 이름 자리에 이메일을 입력 후 엔터를 친다
**기대 결과:** 소속팀 조회 없이 바로 비밀번호 입력창으로 커서가 이동한다
**결과:** [x] 통과 / [ ] 실패

## TC-003: Tab/마우스로 필드 이탈 시 기존 동작 회귀 확인
**조건:** `/login`
**단계:**
1. 이름 입력 후 Tab 키(또는 마우스 클릭)로 다른 필드로 이동
**기대 결과:** 기존과 동일하게 소속팀이 자동완성된다 (엔터를 쓰지 않아도 정상 동작)
**결과:** [x] 통과 / [ ] 실패

## TC-004: 안내 문구 확인
**조건:** `/login`
**단계:**
1. 이름 입력창 아래 안내 문구를 확인한다
**기대 결과:** "동명이인이 있을 수 있어 소속팀과 함께 계정을 구분합니다. 입력 후 엔터를 치세요."로 표시된다
**결과:** [x] 통과 / [ ] 실패

**기대 결과:** 여전히 로그인이 차단된다 (엔터 흐름 추가로 인한 FIX-007 회귀 없음)
