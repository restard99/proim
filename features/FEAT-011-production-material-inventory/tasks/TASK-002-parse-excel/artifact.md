## 이슈 및 결정사항
실제 파일을 컴파일 후 직접 실행해 검증하는 과정에서 3가지 실제 데이터 특이사항을 발견해 대응했다:

1. **비고 값이 헤더 열(O)이 아니라 한 칸 옆(P)에 입력된 행이 섞여 있음** (수기 작성 오차로 추정) — 매핑된 비고 열부터 몇 칸 더 훑어 비어있지 않은 값을 모두 모으도록 `getRemark()`를 추가
2. **합계 행이 숫자만 있고 텍스트 셀이 없어 "빈 행"으로 오판되던 문제** — `cellText()`가 수식 셀의 숫자 결과를 문자열로 반환하지 않아서 발생. 숫자 결과도 문자열로 반환하도록 수정하고, 빈 줄 바로 다음 행을 한 번 더 살펴 합계 행이면 챙기고 끝내는 lookahead 로직 추가 (그 뒤 결재란 등은 보지 않음)
3. **반제품 표의 재고단위 헤더가 "단위"가 아니라 "재고\n단위"로 표기됨** (두 표가 완전히 같은 서식이 아니었음) — stockUnit 매처가 "단위"/"재고단위" 둘 다 받아들이도록 확장

## 검증 방법
`npx tsc`로 이 파일만 단독 컴파일(esnext, bundler resolution) 후, `server-only` import를 제거한 컴파일 결과물을 실제 엑셀 파일에 대해 직접 실행 — 파싱 결과를 원본 셀 값과 하나씩 대조. 이후 스크립트/컴파일 산출물은 정리(삭제)했다.
