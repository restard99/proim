# 원재료,반제품 현황(생산) 기획서

## 개요
생산팀이 수기로 관리하는 "원재료 및 반제품 입출고현황" 엑셀을 업로드하면, 같은 데이터를 앱 화면에서 표로 조회할 수 있게 한다. 왼쪽 탭의 "생산일지" 바로 아래에 새 메뉴로 추가한다.

## 사용자
생산팀 팀원/팀장 (업로드·조회), 관리자(조회)

## 해결하는 문제
현재는 이 재고 현황이 엑셀 파일로만 존재해서, 파일을 직접 열어봐야만 원재료·반제품 재고를 확인할 수 있다. 다른 팀(예: 영업채산팀, 임원실)이나 다른 담당자가 최신 현황을 확인하려면 파일을 따로 전달받아야 한다.

## 기대 효과
- 엑셀을 업로드하기만 하면 웹 화면에서 바로 재고 현황을 조회 가능
- 과거 업로드 이력을 날짜별로 남겨, 특정 시점의 현황도 다시 확인 가능
- 생산일지·생산의뢰서와 동일한 UX 패턴이라 팀에서 이미 익숙한 방식으로 사용 가능

## 범위
### 포함
- 왼쪽 탭 "생산일지" 바로 아래에 "원재료,반제품 현황" 메뉴 추가 (생산팀 전체 + 관리자 조회, 생산팀 전체 + 관리자 업로드 — 생산일지와 동일한 권한 구조)
- 엑셀 업로드 → 두 표(원재료·부재료 / 반제품) 파싱 → Supabase 저장
- 업로드 이력을 날짜별로 목록에 쌓고, 날짜를 선택해 그 시점의 현황을 조회 (기준일은 엑셀 제목 행에서 자동 추출)
- 화면에서 "원재료·부재료" / "반제품" 두 표를 탭 또는 섹션으로 구분해 표시
- 삭제 기능 (업로드한 본인 또는 관리자) — 기존 생산일지 패턴과 동일

### 제외
- 결재란/원염재고 요약/선별전후 요약 등 부속 표 파싱
- Y-ERP 연동 (이 화면은 순수 업로드 데이터만 사용, 생산의뢰서의 Y-ERP 매칭 같은 기능 없음)
- 항목 수정 기능 (생산의뢰서처럼 업로드 후 값 수정 — 이번 범위에서는 없음, 필요 시 추후 추가)
