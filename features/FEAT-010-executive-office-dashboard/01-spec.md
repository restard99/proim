# 임원실 대시보드 (주간업무보고 / 손익자료) 기획서

## 개요
임원실(사장/회장) 전용 메뉴로, 회사 전체의 주간 실적과 손익 현황을 한 화면에서 파악할 수 있는 대시보드를 만든다. "주간업무보고" 탭과 "손익자료" 탭 2개로 구성한다.

## 사용자
`team = "임원실"`인 계정 (사장, 회장). 두 탭 모두 열람 전용.
목표(계획) 수치 업로드는 admin role 계정이 담당한다 (관리자 페이지).

## 해결하는 문제
현재는 전략기획실이 매주 PPT/엑셀(F드라이브 "주간업무보고" 폴더)로 사업장별 실적을 수기 취합해 별도로 공유하고 있다. 시스템 내에서 임원이 실적과 손익을 바로 조회할 수 있는 창구가 없다.

## 기대 효과
- 임원이 매주/매월 회사 전체 및 사업장별 실적·손익을 시스템에서 바로 확인
- 실적/전년동월 비교 데이터는 Y-ERP에서 자동 집계되어, 전략기획실의 수기 취합 부담이 줄어듦(계획 수치만 입력하면 됨)
- 임원이 궁금한 부분을 댓글로 남기면 전략기획실이 확인 가능

## 범위

### 포함

**공통**
- `team = "임원실"` 계정만 두 탭 열람 가능 (admin은 기존 정책대로 항상 열람 가능)
- 좌측 메뉴에 "임원실" 섹션 신설, 하위에 "주간업무보고" / "손익자료" 탭

**주간업무보고 탭**
- 기존 F드라이브 주간 보고서(`26.07.14 주간` 기준) 중 아래 6개 페이지를 화면으로 재구현:
  1. 전 사업장 매출실적 요약 (태평소금/태평염전/섬들채/박물관 — 주간·월간·전년동월 비교)
  2. 태평염전 매출 실적 (판매처별 상세)
  3. 태평염전 생산 실적 (월별 계획/실적, 공구별 실적)
  4. 태평소금 생산 실적 (천일염/가공염, 주간 연장근무)
  5. 태평소금 영업 실적 (판매처별 상세)
  6. 섬들채 매출 실적 (채널별 상세)

- 데이터 출처:
  - **매출 실적 / 전년동월 실적** (전 페이지 공통): Y-ERP 자동 집계
  - **태평염전 생산 실적/계획**: 기존 `/saltfield-production`(염전관리팀이 엑셀로 업로드하는 기존 FEAT-007 기능)의 `saltfield_production_records` 테이블을 그대로 조회해서 사용. 새로 만들 것 없음
  - **태평소금 생산 계획, 매출 계획(목표)**: Y-ERP·기존 테이블 어디에도 없어 관리자 페이지 엑셀 업로드로 신규 입력 (아래 참고)
- 임원실은 주차별로 넘겨보기 가능 (지난 주 / 다음 주)
- 임원실이 보고서에 댓글을 남길 수 있고, 전략기획실이 확인 가능

**목표(계획) 엑셀 업로드 (관리자 페이지)**
- `/admin` 하위에 신규 업로드 화면 추가, **admin role만 접근 가능** (시스템 관리자가 전략기획실로부터 받은 파일을 대리 업로드)
- 업로드 대상: 법인별(태평소금/태평염전/섬들채/박물관) 매출 목표(주간/월간/연간) + 태평소금 생산 목표(천일염/가공염, 주간/월간)
- 태평염전 생산 목표는 이 업로드에 포함하지 않음 (염전관리팀이 자체 업로드하는 기존 기능으로 대체)

**손익자료 탭**
- 법인별 탭 구분 (태평소금 / 태평염전 / 섬들채)
- Y-ERP에서 자동 집계 (수동 입력 없음)
- 요약 수준 손익: 매출 / 매출원가 / 판관비 / 영업이익 (대분류)
- 조회 기준: 월 선택 + 전월 대비, 월 누적(YTD) + 전년 대비를 함께 표시
- 엑셀/PDF로 내보내기 가능

### 제외
- 주간업무보고 원본의 나머지 페이지(시세, 추정, 객단가비교, 인당생산성, 신제품 등) — 이번 범위 아님
- 손익자료의 계정과목 단위 상세 내역 (대분류 요약까지만)
- 다른 팀(생산팀/영업팀 등)이 직접 각자 보고서를 작성해 올리는 기능
