# TASK-009: 손익자료 화면 — 아티팩트

## 상태: 완료 (브라우저 최종 확인은 6단계 테스트에서 진행)

## 구현 내용
법인 탭(태평소금/태평염전/섬들채) + 월 선택 화면. 세 개의 표를 보여준다:
1. 당월 손익 — 전산(Y-ERP)/확정(회계팀)/차이 (사용자가 참고자료로 준 워크북의 "회계팀발표 대조" 시트와 동일한 구조)
2. 당월 손익 — 전월·전년동월 대비 (확정 자료가 있으면 확정값, 없으면 전산값을 "대표값"으로 써서 추세를 보여줌)
3. 월누적(YTD) 손익 — 전년 대비

엑셀 내보내기는 서버에서 exceljs로 만든 파일을 base64로 내려받아 브라우저에서 Blob 다운로드. PDF는 별도 라이브러리 없이 `window.print()`.

## 생성/수정된 파일
- `app/actions/executive-pl.ts` (신규): `getProfitLoss`, `exportProfitLossExcel`
- `app/(app)/executive/pl/page.tsx` (신규)
- `components/executive/ProfitLossView.tsx` (신규)

## 이슈 및 결정사항
"전월·전년동월 대비"와 "YTD" 표는 매달 확정 자료가 있을 수도 없을 수도 있는 상황을 고려해, 확정값이 있으면 그걸, 없으면 전산값(매출원가는 0으로 취급)을 "대표값"으로 써서 계산했다. 이 경우 표 하단에 "확정 자료가 없는 달이 포함되어 잠정치" 안내 문구를 표시해 오해를 방지했다.
