# TASK-005: Y-ERP 전산 손익 집계 모듈

## 목적
손익자료 탭의 "전산(Y-ERP 자동집계)" 열에 쓸 매출/판관비를 집계한다. 매출원가는 일반전표에 기록되지 않음을 확인했으므로 이번 모듈에서는 계산하지 않는다 (03-decisions.md 참고, 회계팀 확정 자료는 TASK-006에서 별도 업로드).

## 작업 범위
- 생성할 파일: `lib/yerp/executive-pl.ts`
  - 매출: TASK-003의 `getSalesTotalByCorp`/`getSalesByCustomer`와 동일한 `AC_PURC_SALE_T` 방식 재사용
  - 판관비: 일반전표(`AC_GNR_SLIP_T`) 계정 `0802`~`0840` 합계
- 태평염전(0400)·섬들채(0360)도 동일 계정코드(0802~0840)로 판관비가 실제로 잡히는지 실데이터로 검증

## 완료 기준
- [ ] 법인코드 + 기간(년월)을 넣으면 전산 매출/전산 판관비 반환 (매출원가는 null로 반환, 화면에서 "-" 표시)
- [ ] 태평소금/태평염전/섬들채 3개 법인 모두 실데이터로 검증 (금액이 0이 아니고 상식적인 범위인지 확인)
- [ ] 전월/전년동월 등 임의 기간 비교가 가능하도록 기간 파라미터화
- [ ] `npx tsc --noEmit` 통과
