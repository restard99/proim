# TASK-005: Y-ERP 손익 자동집계 모듈

## 목적
손익자료 탭에 쓰일 매출/매출원가/판관비/영업이익을 일반전표에서 계정과목 기준으로 집계한다.

## 작업 범위
- 생성할 파일: `lib/yerp/executive-pl.ts`
- 태평염전(0400)·섬들채(0360)의 매출/매출원가/판관비 계정코드를 태평소금(0460)과 동일한 방식으로 직접 조회해 검증 (03-decisions.md에 정리된 0460 계정코드가 다른 법인에도 그대로 쓰이는지 확인, 다르면 법인별 코드 매핑 추가)

## 완료 기준
- [ ] 법인코드 + 기간(년월)을 넣으면 매출/매출원가/판관비/영업이익(계산값) 반환
- [ ] 태평소금/태평염전/섬들채 3개 법인 모두 실데이터로 검증 (금액이 0이 아니고 상식적인 범위인지 확인)
- [ ] 전월/전년동월 등 임의 기간 비교가 가능하도록 기간 파라미터화
- [ ] `npx tsc --noEmit` 통과
