# TASK-003: Y-ERP 매출 집계 모듈 — 아티팩트

## 상태: 완료

## 구현 내용
법인별/판매처별/섬들채 채널별 매출을 Y-ERP `AC_PURC_SALE_T`(매출조회)에서 집계하는 모듈을 만들었다.

당초 계획(03-decisions.md)은 기존 `sales.ts`(PM_SALES_MGMT 기반)를 확장하는 것이었으나, 실데이터 확인 결과 `PM_SALES_MGMT`는 태평소금(0460)에만 데이터가 있고 태평염전/섬들채/박물관은 0건이었다. 대신 4개 법인 모두 실데이터가 있는 `AC_PURC_SALE_T`(PURC_SALE_SEC='1')로 새로 구현했다.

섬들채 채널 구분(소금가게/카라반 등)은 Y-ERP에 별도 분류 코드가 없어서, 실제 거래처명이 `"{채널명}-소비자매출"` 관행으로 등록돼 있는 걸 확인하고 그 이름 규칙으로 파싱했다. 태평염전의 도매/관내기타/서비스사업부 구분은 근거가 될 만한 필드나 이름 규칙을 찾지 못해 이번 모듈에는 넣지 않고, 판매처별 목록(금액순)만 제공한다 — 화면(TASK-008)에서 상위 거래처 + 기타로 보여주는 방식으로 대체.

## 생성/수정된 파일

## 이슈 및 결정사항
태평염전 판매처를 PPT처럼 도매/관내기타/태평소금/서비스사업부 4개 그룹으로 정확히 나누는 로직은 이번에 넣지 않았다. 근거 데이터(분류 코드, 이름 규칙)를 찾지 못했고, 억지로 추측해서 분류하면 잘못된 숫자를 보여줄 위험이 있다고 판단했다. 대신 판매처별 금액 목록을 그대로 제공하고, 화면에서 상위 거래처와 "기타" 합계로 표시하는 방식(태평소금 영업 페이지와 동일한 패턴)으로 대체한다.
