# FIX-001 테스트 케이스

## TC-001: 이메일 인라인 수정 성공
**조건:** 관리자 계정으로 `/admin/approvals` 접속
**단계:**
1. "전체 사용자" 표에서 아무 계정의 이메일 칸 클릭
2. 새 이메일 주소 입력 후 "저장"
**기대 결과:** 입력창이 사라지고 표에 새 이메일이 반영된다
**결과:** [ ] 통과 / [ ] 실패

## TC-002: 변경된 이메일로 비밀번호 찾기 동작 확인
**조건:** TC-001에서 이메일을 실제 수신 가능한 주소로 변경
**단계:**
1. 로그아웃 후 `/forgot-password`에서 해당 계정 이름+소속팀으로 비밀번호 리셋 요청
**기대 결과:** 새로 등록한 이메일로 재설정 메일이 도착한다
**결과:** [ ] 통과 / [ ] 실패
