- `components/saltfield/MaterialUploadButton.tsx` (신규): 생산량 업로드 버튼과 동일한 패턴
- `components/saltfield/MaterialInventoryTable.tsx` (신규): 월 선택 드롭다운 + 검색(업체명/품명, 클라이언트 필터) + 표 + "전체 교체" 안내 문구 + 빈 상태
