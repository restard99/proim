# 염전관리팀 화면 기획서

## 개요
염전관리팀 전용 업무 화면을 만든다. 업무일지는 이미 전 팀 공통으로 제공되는 기능을 그대로 쓰고, 이 팀만의 두 가지 업무게시판(생산량, 부자재재고현황)을 엑셀 업로드 기반으로 새로 추가한다.

## 사용자
- 염전관리팀(팀원/팀장): 생산량·부자재재고현황 엑셀 업로드 및 조회
- 관리자: 두 게시판 모두 조회 가능

## 해결하는 문제
- 염전 현장의 일일 생산량과 부자재 재고 현황이 각자 엑셀 파일로만 관리되고 있어, 팀 안에서 공유·조회하기가 번거롭다
- 매주 작성하는 주간업무보고 엑셀(생산실적 포함)을 그대로 시스템에 올리면 굳이 별도로 데이터를 재입력하지 않아도 조회할 수 있게 한다

## 기대 효과
- **업무일지**: 기존 전 팀 공통 기능을 그대로 사용 — 별도 개발 불필요
- **생산량 게시판**: 팀원 누구나 주간업무보고 엑셀(`생산-염전` 탭)을 업로드하면, 날짜별 공구/호수별 일일 생산량(포 단위)과 주간·월간·연간 계획 대비 실적이 시스템에 쌓여 날짜별로 조회할 수 있다
- **부자재재고현황 게시판**: 팀원 누구나 부자재 입출고내역 엑셀을 업로드하면, 업체별·품목별 현재 재고 수량과 재고금액을 조회할 수 있다. 새로 업로드하면 직전 상태를 대체한다 (재고는 "지금 얼마나 있는지"가 중요하므로 최신 상태만 유지)

## 범위

### 포함
- 염전관리팀 전용 "생산량" 페이지: 엑셀(.xlsx) 업로드 → `생산-염전` 탭에서 날짜별 데이터 파싱 → 날짜별 목록/조회 (과거 업로드 기록 누적)
  - 파싱 대상: 일자, 공구·호수별 일일 생산량(G~AY열, 1공구~3공구 각 호), 일일실적 합계
  - 주간 마감일 행에서 주간계획/주간실적/계획비, 월간계획/월간실적/달성율을 함께 저장
  - 월말 행에서 월누적계획/월누적실적/달성율, 연간계획/연간실적/진행율을 함께 저장
  - 값이 실제로 채워진 날짜만 저장 (연간 템플릿 상 비어있는 미래 날짜는 제외)
- 염전관리팀 전용 "부자재재고현황" 페이지: 엑셀(.xlsx) 업로드 → 월별 시트에서 업체명/품명/단가/이월재고/입고/출고/재고/재고금액/비고 파싱 → 업로드 시점 기준 최신 상태로 전체 교체
- 두 페이지 모두 팀원/팀장 구분 없이 업로드 가능
- 접근 권한: 염전관리팀 전체 + 관리자만 조회 가능, 다른 팀은 접근 불가

### 제외
- 생산량 게시판의 "전년대비" 비교 (엑셀의 `과거생산` 탭, 구조가 달라 별도 검토 필요 — 이번 범위에서 제외)
- 업로드 이력 감사 로그, 수정 기능 (일단 업로드/조회만, 잘못 올리면 관리자 문의로 삭제)
- 부자재 재고 부족 알림, 발주 연동 등 추가 로직
