# 염전관리팀 화면 테스트 케이스

## 테스트 전 준비사항
- 개발 서버가 실행 중이어야 합니다 (`http://localhost:3000`)
- 염전관리팀 소속 계정(팀원 1개, 가능하면 팀장 1개)과, 비교용으로 다른 팀 계정이 필요합니다
- 테스트용 엑셀 파일: `태평염전 염전관리팀 2026년 8월 1주차 주간업무보고(생산실적 포함).xlsx`, `태평염전 2026년 부자재 입출고내역.xlsx`

## 정상 케이스

### TC-001: 메뉴 노출 확인
**조건:** 염전관리팀 계정으로 로그인
**단계:**
1. 사이드바 확인
**기대 결과:** "업무일지"(공통), "생산량", "부자재재고현황" 메뉴가 모두 보인다
**결과:** [ ] 통과 / [ ] 실패

### TC-002: 생산량 업로드
**조건:** 염전관리팀 계정, `/saltfield-production` 접속
**단계:**
1. "엑셀 업로드" 클릭 후 주간업무보고 엑셀 선택
**기대 결과:** 업로드 완료 후 날짜별 목록에 새 행들이 추가되고, 요약 카드(최근 일일 생산량 등)가 갱신된다
**결과:** [ ] 통과 / [ ] 실패

### TC-003: 생산량 상세 조회
**조건:** TC-002 완료
**단계:**
1. 목록에서 아무 날짜나 클릭
**기대 결과:** 해당 날짜의 1/2/3공구별 호수 생산량 표와 주간/월간/연간 실적 요약이 보인다
**결과:** [ ] 통과 / [ ] 실패

### TC-004: 같은 날짜 재업로드
**조건:** TC-002에서 업로드한 것과 같은 기간이 포함된 파일을 다시 업로드
**단계:**
1. 같은(또는 겹치는 날짜가 있는) 파일을 다시 업로드
**기대 결과:** 날짜가 중복 생성되지 않고 해당 날짜 값만 갱신된다
**결과:** [ ] 통과 / [ ] 실패

### TC-005: 부자재재고 업로드
**조건:** 염전관리팀 계정, `/saltfield-inventory` 접속
**단계:**
1. "엑셀 업로드" 클릭 후 부자재 입출고내역 엑셀 선택
**기대 결과:** "전체 교체" 안내 후 업로드 완료, 표에 업체별/품목별 재고가 나타난다
**결과:** [ ] 통과 / [ ] 실패

### TC-006: 부자재재고 검색/월 선택
**조건:** TC-005 완료
**단계:**
1. 검색창에 특정 업체명(예: "동원") 입력
2. 월 선택 드롭다운에서 다른 달 선택
**기대 결과:** 검색어에 맞는 행만 남고, 월을 바꾸면 해당 월 데이터로 즉시 바뀐다
**결과:** [ ] 통과 / [ ] 실패

### TC-007: 부자재재고 재업로드(전체 교체)
**조건:** TC-005 완료 후 같은 파일 또는 수정된 파일을 다시 업로드
**단계:**
1. "엑셀 업로드"로 다시 업로드
**기대 결과:** 기존 데이터가 새 내용으로 완전히 교체된다(중복 안 남음)
**결과:** [ ] 통과 / [ ] 실패

### TC-008: 팀원 업로드 권한 확인
**조건:** 염전관리팀 "팀원"(팀장 아님) 계정으로 로그인
**단계:**
1. 생산량/부자재재고현황 각각에서 엑셀 업로드 시도
**기대 결과:** 팀장이 아니어도 정상적으로 업로드된다 (팀장 제한 없음)
**결과:** [ ] 통과 / [ ] 실패

## 예외 케이스

### TC-009: 다른 팀 접근 차단
**조건:** 염전관리팀이 아닌 계정으로 로그인
**단계:**
1. 사이드바 확인
2. 주소창에 `/saltfield-production`, `/saltfield-inventory` 직접 입력해 접근 시도
**기대 결과:** 사이드바에 두 메뉴가 안 보이고, 직접 URL 접근 시 홈으로 리다이렉트된다
**결과:** [ ] 통과 / [ ] 실패

### TC-010: 잘못된 양식 업로드 (생산량)
**조건:** `/saltfield-production`
**단계:**
1. "생산-염전" 탭이 없는 엑셀 파일(또는 다른 종류의 xlsx)을 업로드
**기대 결과:** "생산-염전 탭을 찾을 수 없습니다" 등 명확한 오류 메시지가 뜨고 저장되지 않는다
**결과:** [ ] 통과 / [ ] 실패

### TC-011: 엑셀이 아닌 파일 업로드
**조건:** `/saltfield-production` 또는 `/saltfield-inventory`
**단계:**
1. .xlsx가 아닌 파일(예: .pdf, .jpg)을 업로드 시도
**기대 결과:** "엑셀(.xlsx) 파일만 업로드할 수 있습니다" 오류가 뜬다
**결과:** [ ] 통과 / [ ] 실패

### TC-012: 데이터 없는 초기 상태
**조건:** 아직 아무것도 업로드하지 않은 상태(신규 테넌트 가정, 또는 확인만)
**단계:**
1. `/saltfield-production`, `/saltfield-inventory` 접속
**기대 결과:** 각각 "업로드된 기록이 없습니다" 빈 상태 화면이 보인다
**결과:** [ ] 통과 / [ ] 실패

### TC-013: 없는 날짜 상세 접근
**조건:** 로그인 상태
**단계:**
1. 주소창에 `/saltfield-production/2099-01-01` 처럼 존재하지 않는 날짜를 직접 입력
**기대 결과:** 404 페이지가 뜬다 (에러로 죽지 않음)
**결과:** [ ] 통과 / [ ] 실패

### TC-014: 관리자 조회 권한
**조건:** 관리자(admin) 계정으로 로그인
**단계:**
1. `/saltfield-production`, `/saltfield-inventory` 접속
**기대 결과:** 염전관리팀 소속이 아니어도 관리자는 정상 조회된다
**결과:** [ ] 통과 / [ ] 실패
